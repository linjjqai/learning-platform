# 学习平台（多课程 · 内容可追加）

一个入口，装下所有课程。每门课都是同一套学习体验：30 秒速览 → 核心要点 → 术语表 → 截图 → 时间轴 → 随堂自测，按天推进，进度自动记录。

**这不是"换内容"的模板，而是"往里加内容"的平台**：CRM 这门课已经在里面，之后每加一门课 / 每加一节课，都是新增文件，不动既有内容。

---

## 一、平台现在的样子

```
首页（课程库）            /                     所有课程卡片 + 总统计
└─ 课程首页               /crm/                 课程 Hero + N 天路径 + 全量课时 + 课件
   ├─ 课时页             /crm/L01/             30 秒速览 / 要点 / 术语 / 截图 / 时间轴 / 自测
   ├─ 天数页             /crm/day/1/
   ├─ 术语总表           /crm/glossary/
   └─ 课件页             /crm/materials/
```

- 顶部有**课程切换器**，任何页面都能直接跳到别的课
- 搜索是**跨课程**的：一次搜索命中所有课程，结果标注课程名
- 进度按课程隔离：`localStorage` 里 `{ 课程: { 课时: {...} } }`
- 现有内容：CRM 产品入门（33 课时 / 7 天 / 14 份课件），结构与平台 2026-04 版一致

## 四、往平台里加内容（三种情况）

### 1. 加一节课（已有课程里）

```bash
pnpm new lesson crm L32 "渠道政策与返点" --day 7
```

生成 `content/courses/crm/lessons/L32.md` 骨架，填完内容再 `pnpm build`：
它会自动进入 Day 7 分组、导航、全量课时、搜索索引和进度统计——**不用改任何配置**。

### 2. 加一门新课程

```bash
pnpm new course hr "新员工 HR 制度"
pnpm new lesson hr L01 "入职与考勤" --day 1
pnpm build
```

新课程会出现在首页课程库和顶部课程切换器里，自带独立的天数路径、术语总表、课件页和进度。

### 3. 批量导入现成素材

把课件放进 `_inbox/crm/`（pptx / pdf / docx 都行），然后：

```bash
python tools/extract_material.py _inbox/crm
```

会生成 `_inbox/_extracted/*.md`：每页一块，保留标题、正文、表格、备注，并在 `_index.md` 里列出清单与页数。
之后的动作是我按页内容对照课时，把「速览 / 核心要点 / 术语 / 坑 / 时间轴」补进对应 `lessons/L*.md`。

素材目录约定与命名建议见 `_inbox/README.md`。

## 五、课时怎么写

照 `templates/课程内容模板.md`。front matter 字段：

| 字段 | 作用 |
| --- | --- |
| `id` / `order` / `day` | 课时编号、排序、归属第几天 |
| `title` | 课时标题（不带"课时N"前缀） |
| `duration` | 视频时长，如 `42:10` |
| `video` | mp4 直链渲染播放器；网页地址渲染 iframe |
| `pdf` | 关联课件文件名数组 |
| `tags` | 标签，显示在课时页 |
| `quiz` | 手写题目（可省略，省略则用术语表自动出题） |

正文按**关键词**分区，标题可以按课程习惯改写：

| 识别到 | 渲染成 |
| --- | --- |
| 速览 / 30 秒 | 顶部高亮速览卡 |
| 核心要点 / 要点 | 编号要点列表 |
| 术语 | 术语卡片 + 进术语总表 + 自动出题 |
| 注意 / 易错 / 坑 | 警示卡片 |
| 截图 / 图示 | 截图墙（点击放大、带时间角标） |
| 时间轴 / 节点 | 可点击时间轴（接视频后即跳转） |

## 六、视频与课件

- **视频**：`video` 填 `https://.../lesson.mp4` → 原生播放器，点时间轴直接 seek；填平台嵌入页 → iframe
- **课件**：PDF 放 `content/courses/<课程ID>/pdf/`，在 `catalog.json` 的 `pdfs` 里登记文件名与关联课时；
  不想放本地就改 `build.mjs` 顶部 `REMOTE_ASSETS` 指向外部地址
- **截图**：放 `content/courses/<课程ID>/media/<课时ID>/`，正文写
  `![说明（00:12:30）](../../assets/media/<课时ID>/xxx.jpg)`，时间点会自动变成可点击角标

## 七、视觉系统

- 主色：靛蓝 → 紫 → 品红渐变（品牌、按钮、进度、强调线）
- 每门课一个主色（`course.json` 的 `color`），贯穿课程卡、课程 Hero、课时编号
- 每天一个颜色（七天七色），贯穿路径节点、侧栏徽标、天数页、课时条目
- 每类内容一个强调色：速览(靛蓝)、要点(蓝)、结构与流程(青绿)、术语(琥珀)、易错(玫红)、截图(紫)、时间轴(青)、自测(绿)
- 默认浅色；右上角可切深色（偏紫蓝夜色，不是纯黑白）
- 配色集中在 `platform/assets/app.css` 顶部变量 + `build.mjs` 的 `DAY_COLORS` / `PALETTE`

## 八、已知边界

1. **进度存本机浏览器**：换设备会丢。要"HR 统计完成率"需要加登录和后端。
2. **搜索是前端子串匹配**：中文不需要分词，但不做同义词/拼音/纠错；内容上万条建议换服务端检索。
3. **自测题默认是术语题**：够验收"记住没有"，覆盖不到"会不会配"；要考实操请手写 `quiz`。
4. **课件预览依赖浏览器 PDF 能力**：移动端可能调起下载。

## 九、部署

`dist/` 是纯静态：GitHub Pages / 对象存储 / Nginx / 内网共享盘都能跑，无需后端与数据库。

## 十一、结业测验

- **章节测验**：33 节课每节 4 道单选题，题面在课时页底部「随堂自测」，题库在 `content/courses/<课程ID>/exam.json`
- **结业总测**：25 题，按 7 天分布（Day1=4、Day2=5、Day3=4、Day4=3、Day5=5、Day6=2、Day7=2），页面在 `/crm/exam/final/`
- **交卷规则**：必须全部答完，交卷按钮才可用；交卷后立即按 `exam.json` 里的答案批改，逐题标出正确/错误选项并给出解析，同时算出百分制分数
- **及格线**：`exam.json` 的 `passScore`（当前 60），通过与否在结果区显示
- **成绩保存**：存在浏览器 localStorage（`lp:progress:v2` 的 `crm.__exam`），测验中心的章节列表会显示各节上次得分
- 没有 `exam.json` 时，平台会自动退回「按术语表生成选择题」，所以新课程不配题库也能用

`_inbox/quiz/*.json` 是出题中间产物，改题可以直接改 `exam.json` 后重新 `pnpm build`。

课件原文提取结果在 `_inbox/_extracted/*.md`，改课时前先看它，能核对每条规则出自哪一页。
