# 速览（30 秒看完）

- 作业文档先按"使用说明"新建一份自己的副本，可见范围开放给企业成员、自己的讲师和班主任，否则别人看不到你的完成情况。
- 题型只有两块：客观题（点链接扫码在线练习，提交后截分数页）＋ 配置题（在自己沙盒账号里真实搭建，截图贴在题目下方）。
- 本次作业＝10 道基础配置小题 ＋ 1 道综合场景题 ＋ 14 题常见问题，挑战配置题同样要交。
- 一切从管理后台"组织架构 → 部门与员工"开始：先建部门再建员工；部门名称不可重复、最多 15 级、"全公司"不算一级、负责人只能 1 人。
- 建员工三个关键：目标部门内点新建（主属部门自动带入）、手机号 10 开头共 11 位、汇报对象选自己；系统名和手机号、登录账号不可重复，姓名可重复。
- 建完必须分配角色：不分配会提示"无权查看系统"，且不占用 CRM 用户数；只有分配了角色的人才能看到 CRM 模块。
- 企业级配置分散在四处：企业信息设置（名称/LOGO）、账号安全设置（90 天改密、强制扫码、12 小时登出、代理登录）、员工功能设置（禁发全公司）、水印设置。
- 易错点集中在：导入模板示例行没删、停用后默认列表看不到人、LOGO 不生效、第 6 题与第 7 题找错入口、第 12 题部门重名。

## 核心要点

- **先复制文档再作答**：作业按使用说明新建一份自己的文档，并把可见范围分享给企业成员、自己的讲师以及对应的班主任，其他人才能看到你的完成情况。
- **两类题型，两种提交物**：客观题点外部练习链接、扫码（习惯用微信）注册登录后在线作答，提交即出分数和解析，所以课上不逐题讲，截图交的是"分数页"；配置题必须到沙盒账号把系统真实搭出来，截图交的是"后台操作结果"。
- **本次作业的实际构成**：系统初始化部分＝10 个基础配置小题＋1 道稍大的综合场景题，后面还跟一份 14 题的常见问题（排查看思路＋解决方案路径＋截图）。后续每天都要做当天模块的作业，工作模块起还会出现挑战配置题，讲师明确说"不是挑战题就不需要做了"，挑战题同样要交；不清楚的产品点可以去乐享平台查文档。
- **第 1 题：建部门**：要求建客户成功部、财务部，并在客户成功部下建北京组和贵阳组。前端本来没有任何部门，要先从界面左下角进管理后台，到"组织架构 → 部门与员工"搭建；"全公司"是当前最大单位、本身不算部门，新建要在它旁边的小图标"新建下级部门"，可"确定并继续添加"连续建。
- **部门的五条硬规则与"几级部门"的判断**：部门名称不允许重复；建好后可以拖拽调整层级；编辑部门时界面会显示该部门属于几级，"全公司"不算一级；层级最多 **15 级**；**负责人只能设置一个人**，且负责人默认可看所负责部门下员工的所有 CRM 数据——任命负责人等于同时给了数据权限。第 5 题判断几级就看"编辑部门"里显示的上级部门，也可以在部门管理里点蓝色字体的部门名逐级展开。
- **部门下还有两个角色**：新建部门时可以设**助理**（可看 CRM 模块中本部门员工的所有 CRM 数据）和**工作观察者**（只能看工作模块中抄送范围在其观察范围内的数据）。
- **批量建部门走导入**：部门管理里下载导入模板，必填列只有部门名称、部门状态，照示例文本填完要把示例/提示内容删掉，避免把示例当数据导入。导入后前端会弹导入导出消息，在"导入导出记录"里能看到导入数据量、失败量并下载失败原因；本次演示因忘删示例行且"上级部门"列填错，出现"导入 2 条、失败 2 条"。另一个常见失败原因是部门重名（同名不允许重复），常规做法是加后缀区分（客户成功部一、客户成功部二）；大型集团确实需要全集团同名的，要向纷享销客服务人员额外申请（口播称"灰度项"，即不做全网发布、只小范围部署给有需求企业的功能），开通后才允许重名。
- **第 2 题：建员工**：要在目标部门（客户成功部）里点"新建"，主属部门才会自动带入；手机号用 10 开头并且要是 11 位；汇报对象选你自己。字段查重要记牢：系统名（昵称）在系统内展示、**不允许重复**，姓名**允许重复**，手机号、登录账号**不允许重复**，批量导入时这些字段都会查重；导入必须严格按模板示例格式录入、**不可自行修改表头**；账号开通后只能先用工作模块，初次登录要改初始密码，且密码格式要符合公司设置的密码强度。
- **主属部门与附属部门不是一回事**：主属部门是员工职能上直接归属的部门、**只能有一个**（第 2 题填客户成功部）；工作范围同时涉及其他部门时可设附属部门、**可以有多个**。例：张三既是销售中心负责人又是总裁办成员，主属部门＝销售中心、附属部门＝总裁办。
- **不分配角色会弹提示**：保存时提示"该人员还没有被分配相应的角色，这种情况会造成无权查看系统"，可点"分配角色"直接处理。角色分管理角色（能在后台做管理动作）和业务角色（CRM 内的业务身份），一线销售给业务角色即可。
- **预置管理角色的分工**：系统管理员是系统内最大权限、可操作后台任何设置，建议只开放给公司最高管理者，且**本人不能移除自己的系统管理员角色**，人数可设多个、没有上限；CRM 管理员是 CRM 模块的最大权限，可查看及编辑 CRM 中的所有数据，同样可设多个。预置角色不够用时可以**复制已有角色的权限**自建，例如专门管审批流程的管理员。
- **用户数是两套口径**：总员工数可以按上限把全公司人员都导入，但 CRM 用户数按购买的账号数计算；只有分配了角色的人才占用 CRM 用户数、才能看到 CRM 模块，未分配角色的人仍可用企信、工作等前端基础功能。配额快用满时找纷享销客对接人增加账号或资源配额；管理首页右上角的企业账号是本企业的唯一标识，每个客户都不同。
- **第 3 题：停用再启用，以及"停用"和"禁止登录"的区别**：停用必须先勾选员工，上方操作按钮才会出现；列表默认只显示"在职员工"，看不到被停用的人，要切到"全部"找到他再点"启用"恢复。概念上别混：**禁止登录**只是不让人登录，账号**仍占用企业已使用的配额数**（用在员工已离职、但考勤和审批还要导出的时候）；**停用**才让账号不再占用企业已使用的账号总数。另外已停用员工**无法删除**（要保留他历史发布的信息）、**仍参与新建员工时的查重**、重新启用时**要重新设置权限**；已停用的部门可以删除，前提是该部门下没有发布过任何信息。
- **激活提醒与重置密码**：账号开通后员工一直没登录就是"未激活"，勾选员工点"激活提醒"，系统会自动给未激活的员工发短信提醒登录；员工忘记密码，除本人重置外，管理员也可以在"部门与员工"界面直接重置。
- **第 4 题：改企业名称与 LOGO**：进管理后台 → 企业设置 → 企业信息设置改名称、上传 LOGO；保存后一定要到前端工作台核对，LOGO 不显示通常是"工作台显示"开关没打开，或图片尺寸、裁剪把内容裁掉了。
- **第 9 题在员工功能设置**：进入"信息发送范围设置"，把财务部（或指定员工）设为被禁止，他们再发布分享、日志、审批、任务、日程、公告时，发送范围里就选不到"全公司"，只能按部门或按同事逐个勾选。同一页的前三项也别配错：汇报对象**建议设为不允许修改**（汇报对象默认可查看下级员工的 CRM 数据，放开员工自改，组织架构就乱了）、职位信息**建议不允许修改**（同一岗位被写成不同叫法，后续统计管理都会乱）、手机号和邮箱**建议允许**（员工会涉及换号）。
- **第 6 题是"个人级"隐私**：题目说的是"自己"的手机号不对财务部可见，所以进自己的个人设置 → 隐私设置设可见范围即可。手机号隐私设置是管理员对全员的统一口径——可统一设置员工手机号是否对指定范围公开可见，例如把公司高管电话设为私密，员工个人也能在个人设置里自行调整；但"只针对自己一个人"用个人设置最直接，后台的隔离部门只能按部门隔离，做不到只针对某一个人。
- **第 7 题是"部门级"隐私，入口最易找错**："手机号隐私设置"管的是手机号对指定范围的公开口径，"通讯录安全"管的是全公司的安全数值，两处都与本题无关。本题要去组织架构 → 通讯录隔离：把财务部设为隔离部门，白名单放开客户成功部，再按需设置"是否限制查看通讯录"等选项。
- **第 8 题全在账号安全设置**：密码过期时间改 90 天；扫码登录设置里设非手机端必须扫码；登出规则/登录时长设 12 小时；授权登录访问设置＝管理员可代其他员工登录。沙盒企业可能提示安全配置禁止修改，知道在哪设并截图即可。代理登录还有前提：员工账号必须已被激活（本人用手机号登录过一次），后台操作里才有"代理登录"，复制弹出的链接、新窗口打开即可进入该员工账号。
- **员工设备管理**：员工更换设备登录时，需要该员工的手机号获取验证码后进行授权；后台能查到他用过哪些设备登录。这也是"换个电脑就看不了"这类问题的核对入口。
- **第 10 题在水印设置**：水印内容选"用户名+手机号"，场景勾选企信聊天界面；保存后到前端聊天页即可看到水印效果。
- **综合场景题的四项要求**：销售中心（一级部门）下建销售一部、二部、三部、售前支持部；全公司同事手机号初始互不可见、后期员工可自行选择公开；员工仅可同时登录一台手机设备，且企信对话与 CRM 信息都要加水印；张三、李四入职，并给张三 CRM 管理员权限。
- **14 道常见问题是开放题**：题目直接发给客户、没有上下文背景，只要答案能解决该问题、写明配置路径并附截图即可，可能出现的情况写多种都算正确。几个已被问烂的结论：同一手机号下的多个企业才有双箭头可一键切换，密码不同就只能退出重登；自动退出/被踢多因登录时长到期、单设备限制被挤下线、密码给他人共用；正式账号绑定了自己的电脑，换电脑登录就看不到该企业（设备可在后台解绑）。
- **企业日志的六类与排障对照**：课件把日志分成审计日志（企业管理与用户行为）、登录日志、CRM 日志（CRM 数据操作＋后台配置记录）、导入导出记录（对象数据导入导出）、函数日志（函数运行记录）、流程日志。排障就照这张表定位：客户下某条数据不见了查"CRM 日志-类别：对象-客户"；联系人数据被导出查"导入导出日志-类别：对象-联系人"；某位同事 CRM 权限出了问题查"审计日志-类别：管理-功能权限"；审批流程被改查"CRM 日志-类别：管理-审批流程管理"；查某位员工登录情况查登录日志；查员工开通账号时间查审计日志。
- **多维度管理（本模块的另一块配置）**：启用后系统自动启用区域线、行业线、产品线三套维度，在"组织架构管理 → 多维度管理"里维护层级（例：华东、华北、华南、华中四个一级区域，华南下设广州地区和深圳地区）；可以指定员工负责某个维度，其默认能看所负责维度及其下级维度关联的全部业务数据；启用的业务对象会自动增加对应维度字段，但**不会自动在前台显示**，还要去对象布局里放出来；多维度同样支持列表页筛选、基于条件的数据共享规则和 BI 报表统计。

## 结构与流程

作业完成顺序（有先后依赖，前面不搭好后面会卡住）：

```
0. 准备
 └ 按使用说明新建作业文档副本 → 可见范围分享给企业成员 / 讲师 / 班主任
 └ 客观题：点链接 → 扫码（微信）注册登录 → 作答提交 → 截分数图 → 贴到文档

1. 组织架构（后台 → 组织架构 → 部门与员工） ← 一切配置的前提
 ① 建部门：全公司 → 新建下级部门 → 客户成功部、财务部
  └ 客户成功部下建 北京组、贵阳组（手动新建 或 部门管理导入）
  └ 硬规则：名称不可重复 / 最多 15 级 / 全公司不算一级 / 负责人只能 1 人
  └ 校验：导入导出记录 → 数据量/失败量 → 失败原因（重名 / 上级部门错）
 ② 建员工（必须在目标部门内点新建，主属部门才自动带入）
  └ 手机号 10 开头 11 位 → 汇报对象=自己 → 主属部门=客户成功部
  └ 查重：系统名 / 手机号 / 登录账号不可重复，姓名可重复
 ③ 分配角色（管理角色 / 业务角色） ← 不分配：无权查看系统、不占 CRM 用户数
 ④ 停用 → 切"全部"找到该员工 → 启用（重新启用要重设权限）
 ⑤ 未激活 → 勾选员工点"激活提醒"；忘记密码 → 管理员在列表里重置
 ⑥ 换设备登录 → 员工手机号收验证码授权（员工设备管理）

2. 企业级信息（企业设置）
 └ 企业信息设置：企业名称 + LOGO 上传 → 前端工作台核对（显示开关/尺寸）
 └ 员工功能设置：汇报对象/职位建议禁止修改，手机号和邮箱建议允许
 └ 工作时间：按部门设工作时间、时长与假期（考勤规则只有考勤管理员能建）

3. 隐私与安全（按题目逐条切换菜单）
 └ 第6题 个人设置 → 隐私设置：本人手机号对财务部不可见（个人级）
 └ 第7题 组织架构 → 通讯录隔离：隔离部门=财务部，白名单=客户成功部（部门级）
 └ 第8题 账号安全设置：密码过期90天 / 扫码登录 / 登出规则12小时 / 授权登录（代理登录）
 └ 第9题 员工功能设置 → 信息发送范围设置：禁止财务部选"全公司"
 └ 第10题 水印设置：用户名+手机号，勾选企信聊天
 └ 场景题 多手机设备登录设置：仅允许一台手机
 └ 访问限制设置：按部门限定 IP 范围（超范围：已登录被登出、未登录禁止登录）

4. 综合场景题（依赖 1、3 全部完成）
 └ 销售中心 → 销售一部 / 二部 / 三部 / 售前支持部
 └ 张三、李四入职；张三追加 CRM 管理员角色
 └ 手机号初始互不可见 + 单设备登录 + 企信与CRM水印

5. 常见问题 14 题：排查思路 + 配置路径 + 截图（开放题，合理即可）
 └ 定位靠企业日志：审计 / 登录 / CRM / 导入导出 / 函数 / 流程
6. 挑战配置题：同样要交
7. 每步截图回填文档 → 对照讲师答案自查
```

关键页面路径速查：

- 部门/员工：管理后台 → 组织架构 → 部门与员工（或部门管理）
- 企业名称/LOGO、员工功能设置、手机号隐私设置、工作时间：管理后台 → 企业设置
- 密码、扫码、登出、代理登录、多设备、访问限制、水印：管理后台 → 企业设置 → 企业安全设置 → 账号安全设置
- 部门间隐私：管理后台 → 组织架构 → 通讯录隔离
- 员工设备/设备解绑：管理后台 → 组织架构管理 → 员工设备管理
- 多维度层级：管理后台 → 组织架构管理 → 多维度管理
- 导入结果：管理后台 → 企业日志 / 导入导出记录
- 操作留痕排障：管理后台 → 企业日志（审计 / 登录 / CRM / 导入导出 / 函数 / 流程）
- 外部系统对接：管理后台 → 集成平台管理

## 术语表

| 术语 | 含义 |
| --- | --- |
| 客观题 | 通过外部练习链接在线作答、提交后自动出分与解析的题目 |
| 配置题 | 需要在沙盒账号中真实搭建系统、并附后台截图的题目 |

## 需要注意的点

1. **截图要"截全"，能看出从哪一步到哪一步**：讲师反复强调，只截一个小角自己回头都找不到路径；建议把菜单、列表、弹窗一起截，关键字段用框圈出来。
2. **导入前先处理模板里的示例行**：模板中的示例文本、提示行不能跟着一起导入，本次演示就是因为忘删示例行＋上级部门填错，出现"导入 2 条、失败 2 条"。同名部门还会报"部门名称不唯一"，需加后缀区分或另走申请。
3. **沙盒账号的安全配置可能被锁**：改密码过期、强制扫码时可能提示测试企业安全配置禁止修改，这是正常限制，知道设置位置并截图即可，不要一直试。
4. **第 6 题和第 7 题容易串**：主体是"自己"就进个人设置 → 隐私设置；主体是"某个部门看不到某个部门"就必须进后台做通讯录隔离。手机号隐私设置是管理员对全员的统一口径（还能把高管电话设为私密），通讯录安全管的是全公司那几个开关，两者都不是"只让某一个人看不见"的做法。
5. **不分配角色也能保存成功**：员工建完后只弹提示不拦截，但该员工进系统会无权查看、且不占 CRM 用户数；给客户讲用户数计费时要能说清"总员工数"和"CRM 用户数"是两套口径。
6. **修改离职员工手机号有风险**：把老员工信息直接改成新人，历史记录中的员工信息会被整体替换成新员工，能新开账号就新开；客户口中的"注销账号"在系统里只能做"停用"，已停用员工不能删除。口播第 7 题把"财务部作为被隔离主体"与"客户成功部可查看"说了两遍相近的话，以幻灯片题目"除客户成功部可查看外其他部门都不允许查看"为准。
7. **设了访问限制的 IP 范围，影响的是已经登录的人**：被设置的部门下，超出所设 IP 范围的员工——已登录状态的会被登出，未登录状态的直接禁止登录并使用系统；只有把那条数据删掉，IP 范围才与用户解绑、恢复不受限制。设置前先确认哪些部门真的只在固定网络里办公。
8. **工作时间与考勤规则是两处入口，别混着讲**：工作时间里能给不同部门设工作时间、工作时长和假期，在这里新建假期会在"假期"模块自动创建一份，不需要再去假期模块重复建；考勤模块也能新建考核规则，区别是只有**考勤管理员**可以设置。
