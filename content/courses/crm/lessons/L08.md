# 速览（30 秒看完）

- 字段依赖、布局规则、验证规则都是对象管理的通用小功能，分别管"能选哪些值""看不看得见、改不改得动""存不存得进去"。
- 字段依赖里父字段只能是单选字段，子字段可以是单选或多选字段；父字段选什么，子字段就只出现对应的选项。
- 典型例子有两个：客户等级 1/2/3 级控制客户资产的档位，客户级别（小微/标准/重要/VIP）控制价格优惠等级 A/B/C/D。
- 子字段为必填且只剩一个可选选项时，系统会自动回填勾选，不用人工选。
- 布局规则分字段控制和页面控制：字段控制按条件变字段，页面控制按新建页/编辑页变字段；新建页只能隐藏，编辑页才能隐藏加只读。
- 字段控制里的"显示"和"必填"是两个独立动作，要"出现且必填"必须两个都配。
- 布局规则只在手动新建/编辑、详情页显示时生效，导入、OpenAPI、工作流后动作、批量更新都不生效。
- 验证规则在保存前校验，配规则名称、适用范围、公式（基础/高级）、提示语和是否阻断保存，标点必须是英文。

## 核心要点

- **字段依赖是什么**：指一个单选或多选字段能显示哪些选项，取决于另一个单选字段当前的取值。父字段选了什么，子字段的可选范围就跟着收窄，选项在录入时直接被过滤掉，而不是选完再报错。
- **父字段只能单选，子字段可以多选**：字段依赖的父字段（控制字段）只能是单选字段；子字段（受控字段）既可以是单选，也可以是多选。
- **子字段只剩一个选项会自动回填**：当子字段被设为必填、且按父字段的取值只剩一个可选选项时，系统会自动把这个选项勾上，不用再手动选。
- **场景一：客户等级与客户资产**：客户等级分 1 级、2 级、3 级，客户资产分小于 10 万、10 万至 100 万、大于 100 万三档。录 1 级客户时就要隐藏"小于 10 万"这一档，避免等级与资产自相矛盾。
- **场景二：客户级别与价格政策**：小微客户只能申请 A 级政策，标准客户可选 A、B，重要客户可选 A、B、C，VIP 客户可选 A、B、C、D。如果不做控制，销售可能选错给公司带来损失。
- **用系统规则兜底人工差错**：销售日常难免选错、填错，靠人工复核不现实。字段依赖把限制写进系统，错误的选项在录入时根本不出现，从源头规避风险，也让新建界面更简洁。
- **配置入口：管理后台 → 对象管理 → 客户 → 字段依赖**：点新建关联关系，先选父字段（控制字段），再选子字段（受控字段），确定后才能进入选项映射。
- **设置选项间的对应关系**：映射弹窗左侧是父字段的选项，右侧列出子字段可勾选的选项，支持全选，配好点"一键"再保存。课件里已配好的一条例子是"1 级行业 → 2 级行业"。
- **必须保存才生效**：关系建好但不保存时，回到客户新建页刷新，小微客户仍能选任意等级；保存后再次刷新，小微只能选 A 级，标准只能选 A、B，VIP 才对应 A、B、C、D。
- **布局规则管什么**：让字段在满足某种条件、或处于新建/编辑页面时发生变化，包括显示、隐藏、必填、只读，分字段控制和页面控制两类。
- **字段控制的口播例子**：客户来源选"市场活动"时必须填写市场活动名称，选"客户转介绍"时必须填写介绍人。不同来源带出不同的必填项，界面只留当前场景需要的字段。
- **页面控制的口播例子**：售后处理类字段只在售后流程里才需要填写和处理，新建、编辑页面没必要展示，直接隐藏掉，减少录入干扰。
- **页面控制的第二个用法：只允许新建时修改**：报价申请对象新建时可以填写基本信息，编辑时不允许修改基本信息，其他信息仍可改——做法就是在编辑页把基本信息字段设为只读。
- **字段控制的配置步骤**：以咨询工单布局演示。新建布局规则先填规则名称、Api Name、描述，选择布局，布局规则类型选"字段控制"，再选控制字段；进入画布后设条件"客户是否需要立即处理 等于 是"，动作为显示"今日值班处理人员"并设为必填。
- **字段控制的前端效果**：选"否"时值班人员字段不出现；选"是"时字段出现并带红色星号，必须填写，正好对应"客户要求立即处理才指派值班人员"的业务逻辑。
- **删掉显示动作的对比**：把"显示字段"动作删除后，不论选是选否该字段都显示，但选"是"时仍变成红星必填。可见"显示"和"必填"是两个独立动作，只配条件不配动作则条件不产生可见变化。
- **布局规则只在手填场景生效**：适用范围仅限手动新建/编辑和详情页显示；导入、OpenAPI、工作流后动作的字段变更、批量更新都不生效，别拿它去拦批量导入的数据。
- **页面控制：新建页隐藏字段**：新建工单时"售后回访原因反馈"是售后处理阶段才填的内容，新建页不需要录入。在布局规则里选页面控制、新建页面，把该字段设为隐藏，前端新建页就不再有这一项。
- **页面控制：编辑页只读加隐藏**：工单的"投诉内容"由客服首次录入，后续不应被改动，于是编辑页设为只读；同时把"问题描述"在编辑页隐藏。刷新后编辑数据，投诉内容灰显不可编辑，问题描述不再出现。
- **验证规则是什么**：在新建或编辑对象数据、保存数据之前，校验页面上所填的信息是否合法、是否符合业务要求。它管的是"这条数据能不能存进去"，与字段依赖、布局规则的作用层面不同。
- **验证规则的两个场景**：保存客户时校验手机号是否 11 位、是否通过工商查询；或者公司不允许录入注册资金小于 1 万的客户。讲师现场演示：未经过工商查询的客户原本也能正常提交，说明默认没有任何校验。
- **工商信息校验的配置**：添加规则命名"工商信息校验"，适用范围勾选新建和编辑，选基础模式，取布尔字段"工商注册"，运算符选"不等于真"。讲师特别提醒标点符号必须是英文状态，配好先点"试试"检查公式。
- **拦截效果**：保存后到前端提交未通过工商查询的客户，系统直接提示"客户数据未经过工商查询，请重新核对数据"并挡住提交；把数据改成已通过查询后可正常提交，这就是"阻断保存动作"的效果。
- **活动时间校验**：给活动开始时间、活动结束时间配规则——当开始时间大于结束时间时提示"活动开始时间大于结束时间，请检查后重新提交"。这类跨字段大小比较用高级模式直接写表达式，字段用 Api Name 表示。
- **新建和编辑都会校验**：验证规则的适用范围同时覆盖新建和编辑，讲师在编辑页把结束时间改小后保存，同样被拦下；改到合法时间后才提交成功，说明校验发生在每次保存动作上。

## 结构与流程

字段依赖（管理后台 → 对象管理 → 客户 → 字段依赖）：

```
关系组成
 父字段（控制字段） 只能是单选字段，决定取值范围，如 客户等级：1 级 / 2 级 / 3 级
 子字段（受控字段） 可以是单选或多选字段，如 客户资产：< 10w / 10–100w / > 100w
 设置选项间的对应关系
  左侧 父字段选项 → 右侧 勾选该选项下允许的子字段选项（可全选）
   高服行业 → 互联网、计算机软件
   制造行业 → 家居建材、医疗医药
   快消行业 → 快消品、农牧业
   小微 → A ｜ 标准 → A、B ｜ 重要 → A、B、C ｜ VIP → A、B、C、D
 自动回填
  子字段必填且按父字段取值只剩一个选项时，系统自动勾选该选项
 生效条件
  ① 依赖关系需保存后生效，保存前前端仍可选全部选项
  ② 父子字段在布局中被隐藏时，依赖关系不生效
```

布局规则（对象管理 → 工单 → 布局规则 → 新建布局规则）：

```
基础信息
 规则名称 / 规则 Api Name / 描述
 选择布局 如 咨询工单布局（示例）
 布局规则类型 字段控制 ｜ 页面控制
 选择控制规则的字段 仅字段控制时需要

适用范围
 手动新建 / 编辑、详情页显示时生效
 导入、OpenAPI、工作流后动作的字段变更、批量更新 不生效

类型一 字段控制（按条件变化）
 规则节点 → 条件（字段 运算符 值）→ 规则操作
 条件示例：客户是否需要立即处理 等于 是
 操作：显示字段 ｜ 隐藏字段 ｜ 设为必填 ｜ 设为只读
 生效：条件不满足时字段不出现；满足时才显示（并带红星必填）

类型二 页面控制（按页面变化）
 新建页面 → 隐藏字段（新建页只能隐藏，不能只读）
 编辑页面 → 只读字段 ｜ 隐藏字段（如 投诉内容只读、问题描述隐藏）
 场景：报价申请 新建可填基本信息、编辑锁定基本信息
```

验证规则（对象管理 → 客户 → 验证规则 → 添加规则）：

```
基础信息 规则名称（如 工商信息校验） / 规则 Api Name / 规则描述
适用范围 新建 ｜ 编辑（可同时勾选，两种场景都会校验）
常见校验 手机号 11 位 ｜ 是否通过工商查询 ｜ 注册资金不得小于 1 万 ｜ 结束时间不得大于开始时间
计算公式 基础模式：插入字段 + 插入运算符 + 插入函数，可视化拼装
 高级模式：直接写表达式，字段用 Api Name，标点必须英文
 公式中字段为空时默认值（默认为零）
 对象数据设置 + "试试"（试算）校验公式是否正确
校验失败提示 提示内容，如"客户数据未经过工商查询，请重新核对数据"
阻断保存动作 阻断（不保存）｜ 不阻断（仅提示，仍可保存）
```

三者区别：

| 维度 | 字段依赖 | 布局规则 | 验证规则 |
| --- | --- | --- | --- |
| 管什么 | 能选哪些选项值 | 字段是否可见、可改、必填 | 数据能否保存 |
| 触发时机 | 父字段取值变化时 | 满足条件时／进入新建页、编辑页时 | 点击保存提交时 |
| 作用对象 | 一个受控字段的选项列表 | 字段的显示、隐藏、只读、必填状态 | 整条数据的合法性 |
| 是否拦截保存 | 不拦截，只是选项里选不到 | 不拦截，只是界面变化 | 可拦截（阻断保存动作） |
| 典型场景 | 客户等级 → 客户资产；1 级行业 → 2 级行业 | 立即处理 → 显示并必填值班人员；新建页隐藏售后字段 | 工商查询校验；开始时间不得大于结束时间 |

| 客户资产 | 字段依赖示例中的子字段，取值为小于 10w、10–100w、大于 100w |
| 客户级别 | 客户上的单选字段，取值为小微客户、标准客户、重要客户、VIP 客户 |

| 页面控制 | 布局规则的一种，按新建页或编辑页分别设置字段隐藏与只读 |

| 报价申请 | 页面控制的例子：新建可填写基本信息，编辑时基本信息锁定为只读 |
| 显示字段 / 隐藏字段 | 布局规则中的动作，控制字段在满足条件时出现或消失 |
| 必填 | 布局规则动作之一，生效后字段前出现红色星号，保存时必须填写 |
| 只读 | 布局规则动作之一，字段可见但不可修改（编辑页设置） |
| 验证规则 | 保存数据前校验填写内容是否合法、是否符合业务要求的功能 |
| 适用范围 | 验证规则生效的页面场景，可勾选新建、编辑 |
| 基础模式 | 验证规则公式的可视化编辑方式，通过插入字段、运算符、函数拼装条件 |
| 高级模式 | 验证规则公式的手写表达式方式，字段以 Api Name 表示 |
| 阻断保存动作 | 验证规则不通过时是否禁止保存，可选阻断或不阻断 |
| 工商注册 | 客户上的布尔字段，标记该客户是否通过工商查询，用作校验条件 |

## 需要注意的点

1. **三者的边界要分清**：字段依赖管"能选哪些值"，布局规则管"看不看得见、改不改得动、必不必填"，验证规则管"存不存得进去"。同样一个校验需求，用错功能就会出现"选项能选但保存才报错"或"看不见却能保存"的错位。
2. **字段依赖保存前不算数**：关系建好不保存，前端仍是全部选项可选，讲师的演示正是先不保存让大家看到"任何等级都能选"，保存后才收窄。调试时若没效果，先确认是否已保存并刷新。
3. **布局隐藏会让字段依赖失效**：字段依赖页面顶部明确提示"有依赖关系的字段在布局中被隐藏时，依赖关系将不生效"。把父字段或子字段藏掉之后，别指望依赖还起作用。
4. **显示和必填是两个动作**：讲师删掉"显示字段"动作后，字段在条件不满足时也一直显示，但选"是"时依旧变红星必填。要真正实现"只有满足条件才出现且必填"，两个动作都要配。
5. **新建页不能设只读**：页面控制中，新建页只能设置隐藏字段，隐藏与只读的组合只能落到编辑页上。要实现"新建能填、编辑不许改"，正确做法是在编辑页把字段设为只读，报价申请对象就是这么配的。
6. **验证规则的细节坑**：运算符和括号等标点必须是英文状态，否则公式不通过；配完务必先点"试试"试算；"阻断保存动作"决定是硬拦截还是只提示；适用范围要确认勾了编辑，否则只在新建时校验。
7. **布局规则拦不住导入和接口**：适用范围只覆盖手动新建/编辑和详情页显示，导入、OpenAPI、工作流后动作、批量更新都不生效。要保证外部进来的数据也合法，得靠验证规则或后端校验，别指望布局规则。
8. **子字段只剩一个选项时会被自动勾上**：条件满足后如果子字段必填、且可选值只剩一个，系统直接回填，界面上看不到"选"的动作。测试时别误判成没生效。
9. **这些配置只有 CRM 管理员能做，还要认准布局**：后台的字段配置只有 CRM 管理员有权限，普通员工没有入口；另外多角色员工前端看到的是主角色分配的布局，配完规则要确认目标员工的主角色用的就是这个布局，否则他那边可能看不到变化。

## 关键节点时间轴

[00:00:01] 开场，本课要讲字段依赖、布局规则、验证规则三个对象通用小功能
[00:00:25] 讲字段依赖的定义与两个场景：客户等级对客户资产、客户类型对价格等级
[00:01:30] 进入客户对象的字段依赖标签页，新建关联关系并设置选项间对应关系
[00:02:39] 保存后刷新前端，验证小微客户只能选 A 级、VIP 客户可选 ABCD
[00:03:28] 转入布局规则，说明字段控制与页面控制两种方式
[00:04:33] 以咨询工单布局开始演示，先做字段控制：立即处理才显示并必填值班人员
[00:06:46] 删掉显示动作做对比，观察必填仍生效；随后进入页面控制
[00:07:45] 新建页隐藏"售后回访原因反馈"，编辑页把投诉内容设为只读并隐藏问题描述
[00:09:56] 转入验证规则，说明保存前校验数据合法性的定位
[00:11:22] 配置"工商信息校验"规则：布尔字段不等于真、英文标点、提示内容、阻断保存
[00:12:37] 前端提交被拦截并提示，改成已通过工商查询后正常提交
[00:13:07] 用活动开始时间与结束时间演示跨字段比较，编辑页保存同样被拦
[00:14:59] 三个功能小结：系统自动完成数据校验，更高效也更可靠
