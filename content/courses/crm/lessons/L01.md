# 速览（30 秒看完）

- 讲师蒋黄鑫（客户成功技术交付负责人）用一张思维导图回答四个问题：我在哪个部门、遇事找谁、客户怎么分级、产品怎么卖出去
- 组织架构分三层：前台作战、中台赋能支撑、后台大后方保障
- 前台核心是经营中心，下设北分战区、华东战区、中南战区，另有云动业务部、招商局事业部、西南分公司、贵阳分公司
- 客户按"账号数 + ARR"分 SVIP / VIP / 重要 / 标准 / 小微五级，小微由云动业务部独立经营
- 客户分层经营另设五层：公司战略级 → 战区战略级 → 3A/3B → 分公司标准级 → 小微
- 业务流程六环节：获取客户 → 客户跟进 → 商机跟进 → 签订合同 → 实施交付 → 服务运营，靠续费/增购形成闭环
- 前台与中台是矩阵式关系：实线汇报分公司总经理，虚线汇报中台专业线负责人

## 核心要点

- **前中后台的"作战"比喻**：前台是直接面对客户的战场与作战单元；中台是打仗时提供人、资源、武器弹药乃至医疗救助的支援方，做专业能力支撑与赋能；后台是大后方，负责最基础的保障。三层的关系是"前台打仗、中台支援、后台兜底"。
- **经营中心与三大战区**：前台核心部门是经营中心，下设北分战区、华东战区、中南战区，战区之外还有云动业务部、招商局事业部、西南分公司、贵阳分公司。西南暂不设战区，因为当地市场开拓与经济环境还不足以支撑一个独立战区，暂以分公司方式承载，但不排除一两年内成立。
- **三个特殊单元**：云动业务部服务小微客户，是独立闭环的分公司级经营单元；招商局事业部是为招商局这一家战略客户单独成立的事业部；贵阳分公司定位特殊，只放客户成功顾问组、客户成功技术交付组、云动业务部贵阳组，没有前端销售和实施体系，核心是后端服务经营、效率提升与人才配置。
- **战区、分公司与战区中台**：分公司是最小经营单元，如北分战区下有北京、山东、西北三家分公司；分公司内设渠道部、售前、销售、实施、客户成功，从找客户到服务客户在一个分公司内就能闭环，等于一条完整产业链。战区与分公司平级，战区中台（开源中心、大客户经营中心/销售、行业经营部、大客户交付部）横向支撑下辖分公司。
- **中台六大部门**：市场部（品牌支撑组、数字营销组、SDR 组）、生态渠道部（发展合作伙伴与代理商）、行业部（高服、制造、快消三个行业部）、实施运营部（含 PMO 组）、客户成功运营部（客户成功顾问组、客户成功技术交付组、客户成功运营组）、经营管理部（商务、销售运营）。SDR 组负责线索发展，用电话做初步跟进；PMO 即项目管理办公室，管公司级项目的运营与流程。
- **前台与中台是矩阵式协作**：以分公司客户成功总监为例，实线汇报给分公司总经理，虚线汇报给中台客户成功运营部负责人；实施总监同理。因为分公司总经理不可能精通每条专业线，专业线的人才培养与能力建设由中台负责，中台因此是"强专业、强支撑"的角色。
- **后台四大中心**：研发中心、财务中心、人力资源中心、总裁办。研发分北研（北京）、深研（深圳）与研发管理部；北研按产品线分 SFA、PaaS、数据、平台运营、快消农牧五个业务部，深研负责互联能力（集成平台、订货通、互联平台）与制造行业。财务中心含财务核算组（开票、应收款）、预算分析组、业务核算组（业务绩效测算，关系个人提成与考核）；人力含组织发展与人才服务、HRBP、招聘部、培训部。总裁办下的流程与IT组承接内部 CRM 的流程、表单、配置需求。
- **研发为何南北分工 + 固定四角色**：客户在哪里，研发就贴近哪里——深圳及华南制造客户集中，北京中关村高科技、高服客户集中，客户越多也越能打磨产品。每个产品线/行业线下都固定四个角色：产品经理（需求调研、蓝图与原型设计）、前端开发、后端开发、测试。研发管理部的江雪是研发体系的"大管家"，研发流程、质量或"不知道找谁"的问题都可以找她。
- **客户级别划分的两个维度**：账号数 + ARR（年度周期性合同金额）。费用分一次性费用与周期性费用，只有周期性费用才计入 ARR；例如客户花 120 万买两年，其中 100 万是周期性产品费、20 万是一次性费用，ARR = 100 万 ÷ 2 = 50 万。
- **五个客户级别的门槛**：SVIP 为 ARR ≥ 50 万，VIP 为 25–50 万，重要为 5–25 万，这三个只看 ARR；标准为账号数 ≥ 30 或 ARR ≥ 3 万，小微为账号数 < 30 且 ARR < 3 万。标准与小微是"或"的逻辑：只要账号数或 ARR 任一达标就是标准，例：25 个账号 + ARR 3.5 万 → 标准级别。SVIP/VIP/重要/标准由战区与分公司经营，小微由云动业务部独立经营。
- **客户分层经营战略（五层）**：第五层公司战略级客户（目前只有招商局），成立事业部独立经营；第四层战区战略级客户，由战区大客户部经营；第三层分 3A（分公司战略级客户，分公司大客户组经营）与 3B（分公司常客，即非标准级、非 3A 客户，由分公司销售 + 客户成功经营）；第二层分公司标准级客户，由分公司销售、客户成功、客户成功顾问经营；第一层小微客户，由云动业务部经营。分层不只看"钱"，还要看客户的未来价值、行业影响力与品牌背书，重要级别中行业前三的客户可以被直接"拍"升为 SVIP/VIP。
- **B2B 业务链路与六个流程环节**：B2B 链路是研发/生产 → 寻找客户 → 产品/服务交付 → 售后服务运营 → 续费/增购/转介绍，与 2C 不同，交付不是终点，服务运营会持续带出续费、增购与转介绍。落到纷享销客就是六步流程：获取客户 → 客户跟进（售前）、商机跟进 → 签订合同（售中）、实施交付 → 服务运营（售后）。大多数 SaaS 订阅型公司的流程都相似，差别只在实施交付的周期与难度；要能说清自己在这条链上的哪一环、支撑谁。
- **获取客户与客户跟进**：获客六种方式——销售自开拓、官网营销、广告投放、市场活动（线上直播、线下沙龙/展会）、发展合作伙伴、发展代理商；前三类由市场部负责，合作伙伴与代理商由生态渠道部负责。拿到线索不等于目标客户，还要通过电话/微信/邮件沟通和客户拜访做客户跟进；本产品不适合陌拜，因为产品要讲很久。
- **商机跟进的六个动作**：商机立项（判断真假机会、定商机级别、做预算测算）、需求沟通、方案呈现、POC（Proof of Concept，验证测试，只在大型项目做，尽量规避以节省售前时间）、异议处理、商务谈判。参与方除销售外还有行业部、售前、实施（POC）、客户成功（讲案例），异议处理与商务谈判会拉入法务和商务。
- **签订合同**：合同条款沟通 → 双方盖章 → 支付合同款 → 开票。销售、法务（条款）、实施交付（交付标准）、财务、客户成功（服务条款）、商务经理、经营管理中心都会参与。
- **实施交付与服务运营闭环**：实施交付走"资源申请 → 资源分配 → 项目立项 → 项目实施（启动、需求调研、方案设计、系统配置、UAT 测试、上线准备、试运行、验收）→ 项目交接"，销售提申请，实施部门派项目经理与实施顾问，客户成功经理提前介入、验收后接手。服务运营含客户交接、日常服务、续费、增购、转介绍、健康度提升、流失挽回；一旦出现增购或转介绍就形成新商机，回到商机跟进环节，流程首尾相接。

## 结构与流程

组织架构（前中后台三层）：

```
纷享销客
├─ 前台：经营中心
│ ├─ 三大战区：北分战区 / 华东战区 / 中南战区
│ │ └─ 分公司（最小经营单元）：渠道部 · 售前 · 销售 · 实施 · 客户成功
│ │ └─ 战区中台（横向支撑）：开源中心 / 大客户经营中心(销售) / 行业经营部 / 大客户交付部
│ ├─ 云动业务部（小微客户，独立闭环）
│ ├─ 招商局事业部（战略客户专设）
│ ├─ 西南分公司（暂不设战区）
│ └─ 贵阳分公司（仅客户成功顾问组 / 客户成功技术交付组 / 云动业务部贵阳组）
├─ 中台
│ ├─ 市场部：品牌支撑组 · 数字营销组 · SDR组
│ ├─ 生态渠道部：合作伙伴 · 代理商
│ ├─ 行业部：高服行业部 · 制造行业部 · 快消行业部
│ ├─ 实施运营部：PMO组
│ ├─ 客户成功运营部：客户成功顾问组 · 客户成功技术交付组（项目经理/实施顾问/技术顾问）· 客户成功运营组
│ └─ 经营管理部：商务 · 销售运营
└─ 后台
 ├─ 研发中心
 │ ├─ 北研：SFA业务部（高服行业组：产品经理 / 技术组：前端·后端·测试）· PaaS业务部 · 数据业务部 · 平台运营部 · 快消农牧业务部
 │ ├─ 深研：制造行业部 · 互联业务部（集成平台·订货通·互联平台）· 测试部 · 产品设计部
 │ └─ 研发管理部（江雪）
 ├─ 财务中心：财务核算组 · 预算分析组 · 业务核算组
 ├─ 人力资源中心：组织发展与人才服务 · HRBP · 招聘部 · 培训部
 └─ 总裁办：流程与IT组
```

客户分层经营战略（五层，自高到低）：

- **第五层 公司战略级客户**：目前只有招商局 → 成立事业部独立经营
- **第四层 战区战略级客户** → 战区大客户部经营
- **第三层**
- 3A 分公司战略级客户 → 分公司大客户组
- 3B 分公司常客（非标准级、非 3A 级客户）→ 分公司销售 + 客户成功
- **第二层 分公司标准级客户** → 分公司销售、客户成功、客户成功顾问
- **第一层 公司小微级别客户** → 云动业务部

业务流程（六环节，对应售前/售中/售后）：

```
B2B 业务链路
 研发/生产 ─→ 寻找客户 ─→ 产品/服务交付 ─→ 售后服务运营 ─→ 续费/增购/转介绍
 ▲ │
 └────────────── 形成新商机，回到商机跟进（闭环）←──────────┘

纷享销客业务流程
 ├─ 售前 ─→ ①获取客户 ─→ ②客户跟进
 ├─ 售中 ─→ ③商机跟进 ─→ ④签订合同
 └─ 售后 ─→ ⑤实施交付 ─→ ⑥服务运营 ─┐
 │
 增购 / 转介绍产生新商机 ←────────┘
```

各环节展开：

- **① 获取客户**：销售自开拓、官网营销、广告投放、市场活动（线上直播 / 线下沙龙·展会）、发展合作伙伴、发展代理商
- **② 客户跟进**：电话 / 微信 / 邮件沟通、客户拜访
- **③ 商机跟进**：商机立项 → 需求沟通 → 方案呈现 → POC（Proof of Concept）→ 异议处理 → 商务谈判
- **④ 签订合同**：合同条款沟通 → 合同双方盖章 → 支付合同款 → 开票
- **⑤ 实施交付**：项目实施申请 → 项目资源分配 → 项目立项 → 项目实施（项目启动、需求调研、解决方案设计、系统配置、UAT 测试、上线准备、试运行、项目验收）→ 项目交接
- **⑥ 服务运营**：客户交接 → 日常服务 → 续费 / 增购 / 转介绍 → 健康度提升 → 客户流失挽回

## 需要注意的点

1. **客户级别与客户分层是两套逻辑，不要混用**：级别只看"钱和规模"（账号数 + ARR），是定量；分层要看客户的未来价值、行业影响力与品牌背书，是定性＋定量。所以会出现"重要级别客户被直接拍成 SVIP/VIP""第五层战略客户可能不赚钱甚至亏本也要拿下"的情况。
2. **标准与小微的判定是"或"的关系，最容易算反**：只要账号数 ≥ 30 或 ARR ≥ 3 万任一成立就是标准级别（例：25 个账号 + ARR 3.5 万 → 标准）；两个条件都不满足才归小微。小微客户的经营主体是云动业务部，其余级别归战区与分公司。
3. **ARR 只算周期性费用，且多年合同要按年折算**：一次性实施费等不计入 ARR；120 万签两年、含 20 万一次性费用时，ARR 是 50 万而不是 120 万或 100 万。
4. **战区叫"北分战区"，不是"北方战区"；西南分公司、贵阳分公司不在战区序列里**：西南目前只有分公司没有战区，贵阳分公司更是只承担客户成功与交付职能，没有销售与实施体系，别按常规分公司理解。
5. **前台与中台不是两套平行体系，而是矩阵**：同一个岗位有实线、虚线两条汇报线；要专业支持找中台专业线，要业务结果找分公司。中台是"强支撑"角色，不是发号施令的上级。
6. **一个分公司内就能闭环全链路**：渠道部找客户、售前做方案、销售成交、实施交付、客户成功做服务运营，全部在分公司内完成——理解这一点，才能理解"分公司是最小经营单元"和战区中台只做横向支撑的定位。
