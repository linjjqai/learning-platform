# 速览（30 秒看完）

- 布局＝新建或查看某条数据时界面上看到的字段排列效果，前端页面的呈现都由布局控制。
- 四类布局：列表页、详情页、移动端摘要字段、待处理的流程页面；入口在管理后台 → 对象管理 → 对象 → 布局。
- 一个对象可以建多套布局；布局里只能新建字段和隐藏字段，禁用/删除字段要回字段列表做。
- 新建编辑页布局默认关闭、开启后关不掉，里面没有组件，只能调字段。
- 一个人有多个角色时，前端只看主角色分配的那套布局，其他角色分了也不显示。
- 移动端摘要字段最多显示 8 个且不支持扩容，开"摘要高级布局"才能超过 8 个。
- 业务类型把同一对象的数据再分类，规则是：一个业务类型只对一套布局，一套布局可给多个业务类型，一个角色可用多个业务类型和布局。
- 业务类型落地三步：建业务类型 → 分配布局（角色 × 业务类型）→ 分配业务类型，最后补角色的业务功能权限。

## 核心要点

- **什么是布局**：指新建或查看某条数据时，界面上所看到的字段排列效果。课件把它拆成四类：列表页布局、详情页布局、移动端摘要字段布局、待处理的流程页面布局。
- **布局控制的不只是字段**：详情页上显示的各类按钮、新建数据时新建/编辑页面的字段分布，都是布局在控制。讲师在演示时强调"所有页面都是被布局控制的"，所以配好布局就等于配好了前端的呈现。
- **一个对象可以建多套布局**：同一个对象能建多套布局以呈现不同效果，再按角色（以及业务类型）分给不同的人用，不必用一套布局迁就所有人。
- **配置入口**：在管理后台 → 对象管理 → 客户对象 → 布局模块，能看到该对象下所有布局的整体配置效果。布局按页面类型分（详情页布局、新建编辑页布局、列表页、流程编辑页、待办列表/详情页），每类下面再列具体布局。
- **PC 端与移动端**：很多布局都有网页端和移动端两套，有的布局只有移动端。本课主要讲网页端（PC 端）效果，移动端只做演示。
- **编辑器左侧三组组件**：通用组件是大多数对象都有的；AI 组件是智能相关组件；业务组件与对象的关联关系有关（关联对象的数据）。下方是"字段"区域，按字段类型列出可拖拽的字段，以及"隐藏的字段"。
- **组件可以放进页签**：组件不仅能放在页面主体，也能放到页签位置上。演示中把"相关团队"直接拖进页签，页面主体就空出一块；反过来拖回主体即可。
- **业务流组件**：如果数据配置了业务流或审批流，可以在布局里加业务流组件，用来展示这条数据的流转情况和当前所处的流转节点。
- **字段的新增与隐藏**：从左侧把字段拖到中间"详细信息"区域即可新增，可当场改字段名称，并在右侧设置是否必填；点字段右上角的小眼睛就能隐藏，隐藏的字段会落到"隐藏的字段"里，拖回来就恢复展示，不是删除。
- **布局里能建字段、不能删字段**：布局中可以新建字段，但不能禁用或删除字段——禁用和删除只能在对象的字段列表里操作。这是布局的能力边界，演示时经常有人在这一步找不到删除按钮。
- **字段分组**：字段太多时用"字段分组"收纳同类字段（如把项目相关字段收成"项目信息"，把定位、国家、省市区收成"地区定位"）。讲师特别说明：字段分组只在布局里有，字段管理页的字段列表里没有这个能力。
- **按钮同样可隐藏**：详情页顶部按钮区（编辑、更换负责人、作废等）在布局里也能控制显隐，隐藏后前端不再出现。改完点"保存并退出"生效。
- **新建编辑页布局**：未开启时，新建/编辑页面是系统预设的样子。大多数对象不需要开启，只在两种情况下开：某些功能必须开启后才能使用；或者新建时要填 30 个字段、而详情页只想给别人看 20 个字段。
- **开启后不可逆**：新建编辑页布局一旦打开就不能再关回去，页面会一直按配置的样子呈现。它只负责新建/编辑页，里面没有组件（组件只在详情页展示），能调的只有字段。
- **多角色看主角色布局**：如果一个人有多个角色，前端所看到的布局是他主角色被分配的那套。演示中小王同时有项目管理员、电商通管理员、售后人员等角色，即使给两个角色各分了一套布局，最终看到的仍是主角色（项目管理员）的布局。
- **按角色建多套布局**：可以给售后人员单独新建一套布局，把客户信息里不希望售后看到的字段全部隐藏，只留必要部分，用布局来做数据内容的分级管理。
- **列表页可插图表与容器**：列表页布局可以通过"添加自定义模块"插入已有图表（如首页预设图表、销售管理驾驶舱、市场活动分析等，弹窗里共 31 个可选），还可以加容器并排放两个图表，让数据在同一屏一起查看。
- **列表页管三件事**：列表页布局控制的是多视图展示、筛选条件与字段显示；场景与顶部按钮的显隐也在这里配（演示中把"我服务的"场景隐藏）；打开"显示汇总字段"后可对选中字段做合计，演示里汇总的是销售订单金额，前端显示 1,523.00。
- **移动端摘要字段布局**：手机端看对象列表时展示哪些字段，就配在这里：左侧是手机预览，右侧用"隐藏字段 / 显示字段"两栏拖拽，决定客户名称、1 级行业、成交状态等哪些信息出现在移动端列表和摘要卡片上；还能选显示样式（平铺/收缩）与是否显示标题。**最多显示 8 个字段且不支持扩容，只有开启"摘要高级布局"才能配置超过 8 个**；待处理的流程列表页配置步骤与它相同。
- **什么是业务类型**：业务类型能对某个对象当中的数据再分类，预设对象和自定义对象都可以配置。它不改变对象本身，只是把同一对象下的数据按业务差异分成几类。
- **业务类型解决什么问题**：以工单为例，有的是客户投诉、有的是客户咨询，两类要填的字段不一样。没有业务类型时只能把所有字段都摆在页面上，界面拥挤，必填也不好设置；有了多业务类型，每类只呈现自己需要的字段。
- **布局可以复制**：为每个业务类型各准备一套布局。从已有布局"复制"后再改（如咨询工单布局去掉投诉内容），比从零搭一套快；要做完全不同的布局就直接新建。
- **业务类型与布局的绑定规则**：一个业务类型只能对应一个布局；一个布局可以同时分配给多个业务类型；一个角色可以使用多个业务类型和多个布局。绑定动作在"分配布局"里完成，让布局来匹配业务类型。
- **分配布局与分配业务类型是两步**：分配布局按"角色 × 业务类型"指定用哪套布局；分配业务类型则决定各角色在新建、导入时能用哪些业务类型（含新建、编辑、导入功能权限）。课件举的例子是：售后人员分配"客户投诉"，售前人员分配"客户咨询"。跨部门角色要看到工单，还得去角色权限管理给业务功能权限。
- **前端效果**：新建工单时先选投诉工单还是咨询工单，表单只出现该业务类型对应的字段；客户对象同理，可以分成国内市场客户、国外市场客户，各自只填该填的信息。

## 结构与流程

布局的层级结构：

```
布局
├─ 按端划分
│ ├─ PC 端（网页端）—— 本课重点
│ └─ 移动端（部分布局只有移动端）
└─ 按页面划分（客户对象 → 布局页签）
 ├─ 详情页布局 详情页布局（客户详情页等，一个对象可建多套）
 ├─ 新建编辑页布局 新建/编辑页布局（默认关闭，开启后不可关闭；只能建字段不能删字段）
 ├─ 列表页 列表页默认布局、移动端列表页布局（多视图 / 筛选 / 字段显示）
 ├─ 移动端摘要字段布局 手机端列表与摘要卡片展示的字段，最多 8 个（开"摘要高级布局"可超）
 ├─ 流程编辑页布局 流程布局（流程列表页配置步骤同移动端摘要）
 └─ 待办列表/详情页 待处理的审批流程、待处理业务流流程、待处理任务
```

布局编辑器（PC 端）的三栏：

```
┌──────────────┬────────────────────────────┬────────────────────┐
│ 左：组件/字段 │ 中：画布 │ 右：全局设置 │
├──────────────┼────────────────────────────┼────────────────────┤
│ 浏览更多组件 │ 页签（详细信息/客户财务信息 │ 基础信息：布局名称 │
│ 通用组件 │ /客户地址/费用/回款/…） │ API Name、布局描述│
│ AI 组件 │ 区块（摘要卡片、相关团队、 │ JS 组件 │
│ 业务组件 │ 动态） │ 字段布局 │
│ 字段（字段信息）│ 字段分组（基本信息/地区定位 │ 组件设置：图表等 │
│ 隐藏的字段 │ /系统信息） │ 组件自身参数 │
│ │ 按钮区（编辑/更换负责人/…） │ │
└──────────────┴────────────────────────────┴────────────────────┘
```

业务类型的作用范围与绑定关系：

- **作用对象**：自定义对象（如本课的"工单"）与预设对象都可以配置业务类型
- **作用位置**：新建/编辑页（决定填哪些字段）、导入数据（决定可用哪些业务类型）
- **与布局的对应**：一个业务类型只能对应一个布局（如咨询工单 → 咨询工单布局）；一个布局可以同时分配给多个业务类型；一个角色可以使用多个业务类型和多个布局
- **与角色绑定**：分配布局（角色 × 业务类型 → 布局）、分配业务类型（角色 × 业务类型 → 可用范围）

配置顺序（本课演示的实际顺序）：

```
1. 字段管理：补齐业务字段（工单：投诉类型/投诉内容、咨询类型/咨询内容）
  ↓
2. 业务类型：新增"咨询工单""投诉工单"（列表自带一个预设业务类型 default_c）
  ↓
3. 布局：为每个业务类型各做一套布局（可复制已有布局再改）
  ↓
4. 分配布局：按角色 × 业务类型，指定该角色在该业务类型下用哪套布局
  ↓
5. 分配业务类型：按角色勾选可用的业务类型（新建/编辑/导入）
  ↓
6. 角色权限管理 → 业务功能权限：给需要跨用的角色补工单的查看/新建等权限
  ↓
7. 前端刷新验证：新建时先选业务类型，再看字段是否按布局呈现
```

## 需要注意的点

1. **改完布局必须刷新才看得到效果**：讲师演示时反复强调，前端页面缓存着旧布局，要新开或刷新页面才能看到最新配置；新建业务类型、新建字段后还可能出现排队，需等企业队列跑完。
2. **多角色只生效主角色布局**：这是最容易误判"配了不起作用"的地方。小王同时拥有项目管理员与售后人员角色，两套布局都分配了，前端仍然显示主角色（项目管理员）的那套。排查时先看该用户的主角色是谁。
3. **新建编辑页布局开了就关不掉**：一旦开启，页面永久按配置呈现；而且它里面没有组件、只能调字段。用之前要确认是"某些功能必须开启"或"新建与详情的字段要不一样"这两种场景，别随手打开。
4. **布局里删不掉字段，删字段也不可恢复**：布局里只能新建字段、隐藏字段，找不到"禁用/删除"是正常的，要到对象的字段列表里操作。删除字段会把平台内该字段下的值一并删除且不可恢复，所以先禁用、确认没人用了再删；而布局里的"隐藏"只是不显示，数据还在。
5. **移动端摘要 8 个字段是硬上限**：最多显示 8 个，明确不支持扩容，想多放只能开"摘要高级布局"。别拿"买资源包"的思路给客户承诺扩字段数。
6. **业务类型与布局是两件事，必须成对配好**：业务类型只负责分类和权限范围，真正的字段差异靠布局实现。一个业务类型只能落一套布局，一套布局可以复给多个业务类型，但反过来"给同一业务类型配两套布局"做不到。建完业务类型后要分别建布局、再在"分配布局"里按角色 × 业务类型绑定，漏掉任何一步，前端都不会按预期只显示该类的字段。
7. **"分配布局"和"分配业务类型"是两个不同弹窗**：前者决定"用哪套布局"，后者决定"能用哪些业务类型"。演示里先分配布局、再分配业务类型，最后去角色权限管理补业务功能权限，顺序反了容易漏配。
8. **听转录稿时容易被口误带偏**：口播把"详情页"说成近似"强清业"、"页签"说成"业签/叶鲜"、"咨询工单"说成"资讯工单"、"投诉工单"说成"头速/公诉工单"，布局类型也讲得较散；以幻灯片 2.1 的四类布局（列表页、详情页、移动端摘要字段、待处理的流程页面）为准。
