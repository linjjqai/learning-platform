# 速览（30 秒看完）

- 工作模块管的是"公司内部协同"：分享、日志、审批、任务、公告、日程都在这一页里发，和 CRM 管业务数据是两条线。
- 界面固定四块：左侧分类栏、中间上半发布区、中间下半工作圈信息流、右侧通讯录（含星标同事）与日程。
- 分享的可见范围只看抄送范围（界面上也叫发送范围），跟 CRM 的上下级数据权限无关；发出后不能改，24 小时内发起人可删，过时只能作废重发。
- 日志是对象：三段式格式、业务类型名称、字段、布局都能在后台改；点评人默认是汇报对象，可手动换人，但只能 1 人。
- 日志后台还能设提交规则：提交开始时间、截止时间、提醒设置、补交。
- 审批分自由审批（工作圈发起，自己勾审批人，勾多人要逐个批复）和固定审批（CRM 流程管理，节点固定），后台对应入口是"审批角色管理"。
- 企信、考勤、网盘各有各的应用管理员：企信要企信管理员才看得到后台"企信管理"，考勤要考勤应用管理员才能新建规则和导入数据，网盘要网盘管理员才能在公司文件里建文件夹。
- 草稿箱不只存分享草稿，CRM 各对象新建没保存的内容也进这里；主导航能不能自己排序，由后台"界面定制管理"的开关决定。

## 核心要点

- **课程定位**：工作模块承载公司内部的一切协同动作——企信沟通、发布工作日志，以及后面要讲的分享、审批、任务、公告、日程。它和 CRM 模块的分工是：工作模块管"人对人"，CRM 模块管"人对业务数据"。
- **模块入口与四大区域**：入口在头像下方的主导航里，点"工作"后右侧出现二级菜单：工作圈、我的工作台、我的消息、更多。整页分四块：① 左侧栏，快速分类查看信息和工作圈消息；② 中间栏上半部分，工作协同功能的发布区（可发分享、日志、审批、任务、公告）；③ 中间栏下半部分，工作圈信息流；④ 右侧栏，通讯录、星标同事和日程。
- **工作圈的筛选维度**：信息流默认看"全部"，也可切到"我发出的""我的部门"等维度，看到同事发的分享和日志；"更多"里还能按类型（分享还是日志）、发起人、时间、关键词单独过滤，方便事后找回某条内容。
- **分享的正文与素材**：正文是富文本编辑器，支持加粗、斜体、删除线、链接、清除格式、有序与无序列表，可插小黄豆表情、图片、本地文件附件，也能直接从公司网盘挑文件；另有"添加投票"（针对某个话题发起投票）和"添加表格"——可选表格里没有你要的样式，是系统管理员还没在后台把表格加上。
- **关联业务数据与可见范围**：分享可以关联客户、商机等对象下的数据，关联后这条信息会自动同步到对应的客户、商机下，不用再回工作圈翻；可见范围由"抄送范围"控制（界面有的地方写"发送范围"，选的是同一个字段），需要哪些同事或部门看到就把他们加进去，口径和邮件抄送一致，范围外的人在工作圈刷不到。
- **回执、草稿与发出后的动作**：需要对方点确认就加"回执"人，只是像发朋友圈一样给大家看（最美分享人、好人好事）就不用加。内容没写完可以"保存草稿"，草稿箱在发布按钮附近和下方都有入口，里面连 CRM 各对象新建未保存的内容也一起收。发出后不能直接改，写错只能作废重写；**发出后 24 小时内可由发起人删除**，超时连删除也做不到。同事能回复、发表情、点赞、送能量，觉得好可以收藏，也能把一条分享设为任务。
- **工作模块已对象化**：工作模块里的东西已经不是写死的页面，而是对象化的。日志本身是一个对象，日志里填写的内容是字段，所以后台可以直接调整字段名称、业务类型（日志/周报/月报）以及要填什么内容。没对象化之前，日志和分享长得一样，什么都改不了。
- **后台配置路径**：后台 → 对象管理 → 预设对象管理 → 搜索"日志"，进入后可按"基本信息、字段列表、字段依赖关系、角色权限管理、布局、业务规则、验证规则"逐项调整。日志的预置格式和业务类型名称，课件里也写作在后台"日志管理"里改，指的是同一套对象入口。
- **预设字段、自定义字段与布局**：名称、负责人这类是系统预设字段，不能删改；天气是讲师自建的自定义字段，能编辑也能挪位置，判断方法看 API Name——带 __c 的就是自建字段，开箱时本来没有。布局指页面上字段的排列顺序，在"布局"里把天气挪到时间后面，保存退出、前端刷新就生效。日报、周报、月报三个模板字段长得一致。
- **日志表单字段**：开箱是系统预置的三段式格式，日志内容含摘要、今日工作复盘（原名"今日工作内容"）、心得体会、明日工作计划，后三项是多行文本字段；下面是点评人、天气、关联业务数据、抄送范围和回执。抄送范围与回执的逻辑与分享完全一致。
- **点评人机制**：只有日志对象有点评人字段，**默认取你的汇报对象，也可以手动改成别人**，但只能选一个人。日志发出后，这个人会收到一条"待点评的日志"任务，进去打分（例如 5 分五星）、写评论，点评完成后工作圈里抄送范围内的人都能看到这条点评。抄送范围内的人只能看见，不能做点评。
- **日志的提交规则**：后台能给日志设提交规则——提交开始时间、截止时间、提醒设置、补交。四项一起决定什么时候才能交、什么时候提醒、过了截止还能不能补，缺勤和迟交就是靠这套规则卡出来的。
- **日志与 CRM 业务数据双向沉淀**：日志里能关联客户、商机、订单等对象下的数据。例如日志中关联了某条商机和订单，日志发布后在 CRM 那条商机下面也能看到这条日志的内容，关联信息自动沉淀，两边都不用重复录。
- **自由审批与固定审批**：工作圈里的审批以前叫协同审批，现在统一叫自由审批；CRM 模块里单独的审批流程管理叫固定审批，针对业务流向做固定节点和固定审批人。自由审批由发起人自己勾选审批人，**勾了多人就要逐个批复**，系统按勾选顺序逐级流转。之所以要留这种"非标准流程"，是因为出差借调这类场景每一趟去的地方、接待人、对接人都不同，二三级节点经常临时变化甚至增减，做不成固定流程。
- **审批后台：审批角色与审批单对象**：后台"审批角色管理"分固定审批和自由审批两块——自由审批可以自定义一个审批角色，往角色里加一位或多位员工，配审批流程时审批人直接选这个角色；固定审批则直接设固定的角色、员工。另外每个审批单在后台都是独立对象，可以单独加字段：讲师给审批单加了"申请时间"，保存后加到布局里，前端刷新就出现，请假申请等同理；前端页面布局在"对象管理 → 布局"里调。
- **任务**：用于让不同岗位的同事共同完成一项动作。填写任务内容、上传照片或附件（例如统一上传职业照）、选择执行人（能选部门，也能选一个群组，可选多个）、设完成时间与提醒时间，再选抄送范围。发布后执行人收到待执行任务，完成后上传附件提交，发起人能看到"6 人执行、已完成 1 人"的进度，还能对每个人单独点评、回复，形成闭环。
- **公告**：填写正文，选开始时间、结束时间、是否显示、展示范围，需要确认时再加回执；发完会出现在右侧栏公告区，也能从右侧栏的"+"直接新建。
- **日程**：在工作模块里点"+"新建，填内容、选参与人、设起止时间、全天还是跨天、是否重复（可每天重复直到某天停止）、是否私密，再设抄送范围。创建时点"查看参与人时间"能看这个时间段谁有空、谁已有安排；日历上数字下方的橙色小点表示当天有日程，当天的安排会列在日历下方。参与人是要参加的人，抄送范围只是能看到日程内容的人。
- **企信前端**：点同事发起对话进聊天窗，可以发图片、发文件、发起视频会议和群投票，也能快捷建群、发起任务。群里可增删成员、看群文件库与历史图片视频、把某条消息置顶成"看板"、看消息已读状态、把一句话快速建成日程。**新入群的人如果没被共享历史记录，看不到入群之前发的文档和图片**，拉人进群后可以主动共享历史记录。撤回规则：自己发的消息 30 分钟内可撤回，群主可随时撤回群内任意成员的消息。日志、任务、日程也能分享到群会话里，如果群里有人不在抄送范围，系统会提示是否同步给这些人。
- **企信后台：定制企信群**：系统预置了几种特定场景的群组——客群（基于 CRM 中某个客户直接创建的客户群）、公海群（基于某个公海创建）、部门群（基于组织架构中的部门创建，部门人员增减群成员自动同步）；也能基于 CRM 里的对象自建自定义群组，例如线索池群、商机2.0群。**只有具备企信管理员权限的员工，才在管理后台看得到"企信管理"**。
- **考勤：前端与规则**：手机端"应用"里打开考勤点签到，下班点签退；有异常可发起考勤修正走审批；右上角"…"可看统计（出勤天数、工作时长）。个人设置里能开智能签到/补签（符合条件时系统自动签到或补签，"使用帮助"里还能查看自己适用的是哪条考勤规则）和打卡提醒。后台要先在应用列表把考勤的应用管理员设成自己，前端才会出现"考勤规则"：固定班次或弹性班次、排班（第一班第二班，最多 10 个班次）、最早最晚打卡时间与弹性上班时间；考勤位置要加打卡地点并设有效范围，外勤考勤和 Wi-Fi 打卡能让定位更精准；还要设适用人员、考勤管理员、谁可查看统计，排班支持选人和导入导出。**只有考勤应用管理员能新建考勤规则、导入考勤数据**。
- **网盘**：分公司文件、个人文件、收到的共享文件三类。公司文件只有网盘管理员能新建文件夹，建好后可通过"编辑权限"给其他同事设管理、查看、下载权限；个人文件人人可建可传，要共享就在个人文件里点某文件夹右侧的"设置权限"，按同事或部门逐个设；别人共享给你的文件夹在"收到的共享文件"里看，还能看某份文档的阅读数据。网盘文件可以直接转发到企信，或发分享、发任务时当附件调取。
- **通讯录**：常用区有全公司、星标同事、新同事（近 3 个月内入职）、管理员（系统管理员、CRM 管理员、部门与员工管理员、日志管理员、审批管理员）、服务号，下方是组织架构。在同事名片上点五角星即为星标同事，星标同事固定显示在工作页右上角通讯录位置，@ 同事时也排在最上面；组织架构里还能快速看到某部门的负责人、观察者都有哪些人。
- **个人菜单与主导航**：头像菜单里有全部应用、工作状态、个人设置、登录设备、草稿箱、切换语言、企信设置、主导航设置、意见反馈、在线客服、系统升级说明。工作状态可设个人状态，也能同步请假状态；企信设置管界面与字体大小；在线客服点开直接跳企信里的"纷享客服"服务号；系统升级说明里能翻过往所有版本的升级内容；主导航设置里能调模块顺序（例如把常用的考勤提到上面）。如果某个模块压根没有排序入口，说明后台"界面定制管理 → 主导航 → 是否允许员工自定义主导航"被设成了否，开关打开后前端才会出现。

## 结构与流程

工作模块（主导航"工作"）：

```
工作模块
├─ 左侧栏 工作圈 ｜ 我的工作台 ｜ 我的消息 ｜ 更多（快速分类查看信息与工作圈消息）
├─ 中间栏·上 工作协同功能发布区
│ ├─ 页签：分享 ｜ 日志 ｜ 审批 ｜ 任务 ｜ 公告 ｜ 自定义记录页签（讲师账号自建的记录类页签）
│ ├─ 分享：正文(富文本：加粗·斜体·删除线·链接·清除格式·有序无序列表)
│ │ → 表情·图片·附件·网盘文件 → #话题 → @同事/部门 → 投票·表格
│ │ → 关联业务数据（同步到客户/商机下）→ 抄送范围(发送范围) → 回执 → 发布 / 保存草稿
│ ├─ 日志：日报·周报·月报（业务类型）→ 摘要 → 今日工作复盘 → 心得体会
│ │ → 明日工作计划 → 点评人(默认汇报对象，仅 1 人) → 天气 → 关联业务数据
│ │ → 抄送范围 → 回执 ｜ 后台另有提交规则：开始时间·截止时间·提醒·补交
│ ├─ 审批：加班·请假·出差·差旅报销·普通报销·审批单（业务类型）→ 逐级勾选审批人
│ ├─ 任务：标题 → 内容 → 附件/照片 → 执行人(部门或群组，可多个) → 完成时间
│ │ → 提醒 → 抄送范围 → 发布（再看进度、逐人评价）
│ └─ 公告：正文 → 开始时间 → 结束时间 → 是否显示 → 展示范围 → 回执
├─ 中间栏·下 工作圈信息流（全部 / 我发出的 / 我的部门 / 更多筛选：类型·人·时间·关键词）
└─ 右侧栏 星标同事+常用 ｜ 公告 ｜ 日程（月历，数字下橙点＝当天有日程，可"+"直接新建）
```

后台把日志对象化后的调整链路：

```
后台 → CRM 平台管理 → 对象管理 → 预设对象管理 → 搜索"日志"
 页签：基本信息 ｜ 字段列表 ｜ 字段依赖关系 ｜ 角色权限管理 ｜ 布局 ｜ 业务规则 ｜ 验证规则
 ① 业务类型：日志 / 周报 / 月报 改名（讲师改成了"日报 / 周报"）
 ② 字段：区分系统预设（名称、负责人，不可删改）与自建字段（API Name 带 __c，如"天气"）
 ③ 布局：把"天气"挪到"时间"之后 → 保存 → 退出 → 前端刷新即生效
 ④ 格式与名称：预置三段式格式、业务类型名称在后台"日志管理"调整（同一套对象入口）
 ⑤ 提交规则：提交开始时间 · 截止时间 · 提醒设置 · 补交
```

审批的两条轨道：

```
工作圈内 → 自由审批（原"协同审批"）
 发起：自己勾选审批人（可多个）→ 勾多人逐个批复 → 按勾选顺序逐级流转 → 各自在待办里确认
 后台：流程管理 → 审批流程管理 → 自由审批
      ＋ 审批角色管理 → 自由审批角色（自定义角色，加 1 位或多位员工，配审批人时直接选）
      流程也可预设好审批人，提交后自动按指定顺序审批

CRM 内 → 固定审批
 针对 CRM 对象上的业务单据，节点与审批人预先固定，按业务流程走
 后台：流程管理 → 审批流程管理 → 固定审批
      ＋ 审批角色管理 → 固定审批（设固定的角色、员工）
```

日程与任务的"人"的区别：

- **参与人**：要真正参加这件事的人，可查看其时间是否冲突，日程会展现在对方日历里
- **抄送范围**：只是能看到这条日程内容的人，出现在工作圈信息流中
- **执行人**（任务）：必须提交完成的人，可以是部门，也可以是一个群组，可多个
- **点评人**（日志）：只能 1 人，默认汇报对象，会收到"待点评"任务
- **回执人**（分享/日志/公告）：需要点确认的人

应用层（工作模块之外的常用应用）：

```
企信 会话/群聊 → 群成员 · 群文件库 · 图片视频 · 置顶看板 · 已读状态 · 快速建日程
  · 视频会议 · 群投票 · 发起任务 · 共享入群前的历史记录
 撤回：本人 30 分钟内；群主随时撤回群内任意成员消息
 后台：应用中心管理 → 应用列表 → 企信 编辑（应用管理员＝自己）→ 企信管理
 （可见范围、操作日志、基础设置、外部联系人、群变更提醒、定制企信群）
 定制企信群：客群（基于客户）· 公海群（基于公海）· 部门群（随部门人员自动同步）
  · 自定义群（基于 CRM 对象，如线索池群、商机2.0群）
 ※ 只有企信管理员权限的员工，后台才看得到"企信管理"

考勤 手机端：签到 / 签退 → 统计（出勤天数·工时）→ 个人设置（智能签到/补签·打卡提醒）
  · 使用帮助：查看自己适用的考勤规则
 后台：应用列表 → 考勤 编辑（应用管理员）→ 考勤规则
  ※ 只有考勤应用管理员才能新建考勤规则、导入考勤数据
 规则：固定班次 / 弹性班次 / 排班（≤10 班次）/ 最早最晚打卡 / 弹性时间
 → 考勤位置（地点 + 有效范围、外勤考勤、Wi-Fi 打卡）
 → 适用人员 → 考勤管理员 → 谁可查看统计 → 排班（选人 / 导入导出）

网盘 公司文件（网盘管理员新建 + 编辑权限分给同事）｜ 个人文件（人人可建可传）
 ｜ 收到的共享文件（可看阅读数据）
 共享设置：个人文件 → 文件夹右侧"设置权限" → 指定同事/部门
 → 对方在"收到的共享文件"里可见 → 可转发企信 / 作附件发分享、发任务
```

## 需要注意的点

1. **工作模块的可见范围不受 CRM 数据权限影响**：CRM 里上级默认能看下级的数据，但分享、日志、日程只看"抄送范围"。讲师反复强调这一点——领导没被勾进抄送范围，就是看不到，别以为是权限配错了。
2. **分享/日志发出后不能改，只能作废重发**：写错了要作废再重新写一条；此外分享发出后 24 小时内可由发起人删除，超过这个时间连删除也不行。
3. **日志有两个容易困惑的地方**：一是"日报/周报"是讲师改过名的——开箱时业务类型叫"日志/周报/月报"（口播听着像"日志化/周结化/月结化"），讲师在后台改成了日报、周报，还把"今日工作内容"改成了"今日工作复盘"，你自己账号看到的名字不同属正常；二是只有日志对象有点评人字段，且只能选一个，抄送范围内的人只能看见点评结果、不能自己点评。
4. **"自由审批"和"固定审批"别叫反**：工作圈发布区里的审批（加班、请假、出差、报销）是自由审批，审批人在发起时现场勾选、按勾选顺序流转；CRM 模块里的审批流程管理是固定审批，节点固定。讲师特别强调过名称，因为老资料里还叫"协同审批"。
5. **自由审批有两种形态，前端能不能自选看后台**：前端发起时自己勾审批人，勾了多人要逐个批复；后台审批流程里也可以把审批人预先设好，提交后自动按指定顺序走。所以客户问"为什么我的审批人不能改"，先去看后台这条流程是怎么配的。
6. **"发送范围"和"抄送范围"是一个东西**：分享页有的位置写发送范围，有的位置写抄送范围，选中的是同一个字段，不是两套权限，别当成两个功能去配。
7. **日志点评人默认就是你的汇报对象**：不手动换人，日志发出去就直接派给你的上级；想指定别人点评要自己点开换，而且只能换一个人，换不了两个。
8. **企信拉人进群不会自动给历史记录**：新入群的人看不到入群之前发的文档和图片，需要手动共享历史记录；撤回时限是本人 30 分钟，群主不受限制、可随时撤回群内任意成员的消息。
9. **"添加表格"里没有想要的样式不是 bug**：可选表格要先由系统管理员在后台加上，前端才有得选；同理分享里投票、表格这类素材配不出来时，先查后台而不是怀疑浏览器。
10. **看不到某个功能/模块，先怀疑"应用管理员"和"后台开关"**：看不到"企信管理"，是因为没有企信管理员权限；看不到"考勤规则"或建不了规则、导不了考勤数据，是因为没在应用中心的应用列表里把自己设为考勤应用管理员；网盘公司文件不能新建文件夹，是因为没有网盘管理员权限；看不到主导航排序入口，是因为后台"是否允许员工自定义主导航"被设否。
11. **参与人 ≠ 抄送范围**：日程里参与人要真正参会、会占用对方时间并可查忙闲；抄送范围只是能在工作圈看到这条日程的人，不参会。任务里对应的则是"执行人"，必须提交才算完成。
