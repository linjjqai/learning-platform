# 速览（30 秒看完）

- 本节接着上一节，把作业里"新建自定义对象"这一段完整演示一遍：基本信息 → 布局配置。
- 新建对象要填的就三块：**名称与 API Name、状态、主属性字段**；其余都是可选项。
- 页面上的"可选功能"四个勾（相关团队、全局搜索、动态、修改记录、多字段排序）决定这个对象以后好不好用，按作业要求勾。
- 对象建好后系统会引导进入布局配置，把字段分组、排顺序，前端详情页长什么样就是这里定的。
- 本节演示的对象是"项目"（`project__c`），它是后续业务流作业的发起对象。

## 核心要点

- **新建对象的入口**：管理后台 → 对象管理 → 自定义对象 → 新建，两步：① 基础信息配置 ② 布局配置。
- **基础信息的必填项**：名称（展示名）、API Name（程序标识，建后不可改）、状态（启用/禁用）、主属性字段（字段名称 + API Name，默认 `name`）。
- **对象图标**：可换图标，前端列表和菜单里显示的就是它，作业里一般按业务语义选一个。
- **可选功能的取舍**：相关团队（要不要按团队共享）、全局搜索（能不能被搜到）、动态（有没有动态流）、修改记录（能不能查字段变更历史）、多字段排序（列表能不能多列排序）。勾多了页面更重，按需勾。
- **主属性字段的注意事项**：它承载这个对象的"唯一标识"和"显示名"，被查找关联引用时显示的就是它；预设对象的主属性类型不可改，自定义对象建的时候就要想好。
- **布局配置**：把字段拖进分组、调整顺序、设置必填与只读；前端新建页/详情页的字段顺序就是这个布局。
- **对象与字段的先后**：先把字段在对象上建全（类型要对），再去布局里摆放；布局里不能新建复杂字段，也不能禁用或删除字段。
- **禁用 vs 删除**：字段不用了先禁用，确认没被报表、流程、公式引用后再删除；删除会连同历史值一起清掉，不可恢复。
- **作业验证**：对象建好后，用业务角色账号在前端新建一条记录，确认字段、必填、布局都符合要求。

## 术语表

| 术语 | 含义 |
| --- | --- |
| 自定义对象 | 企业按业务需要新建的对象，与客户、商机等预设对象并列 |
| API Name | 对象的程序标识，创建后不可修改 |
| 主属性字段 | 对象"叫什么"的字段，承载唯一性与显示名 |
| 对象状态 | 启用或禁用；禁用后该对象在前端不可用 |
| 布局配置 | 决定前端新建页、详情页里字段的分组与顺序 |
| 相关团队 | 可选项，开启后支持把人员加到数据的团队里共享 |
| 修改记录 | 可选项，开启后能追溯字段级的历史修改 |
| 全局搜索 | 可选项，开启后该对象的数据可被全局搜索命中 |
| 多字段排序 | 可选项，列表页可按多个字段组合排序 |
| 禁用字段 | 保留字段与历史数据但前端不再使用，可再启用 |
| 删除字段 | 彻底移除字段及其历史值，不可恢复 |

## 需要注意的点

1. **API Name 用英文+下划线**：`project__c` 这种命名是标准写法，别用中文或空格，后面接口、集成都会用到。
2. **主属性字段别选错**：它是查重和查找关联显示的依据，选成"备注"这类可空字段，后面列表全是空白。
3. **可选功能可以后期改，但数据结构会变**：修改记录、相关团队这类开关涉及底层数据，上线后再开要评估影响。
4. **布局里删除不了字段**：想删字段必须回字段列表操作，很多人卡在布局页面找不到删除按钮。
5. **建对象只是第一步**：字段、布局、权限三件事都做完，这个对象才算"能用"。
