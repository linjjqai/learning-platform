# 速览（30 秒看完）

- 界面定制管理就是"千企千面"：导航、菜单、页面、应用、品牌色、企业信息、启动图七类都能自定义，管理员自己搭出符合业务场景的界面。
- 新 UI 给了三样东西：横纵布局一键切换、电脑端和移动端各自的主题色、任意颜色的自定义品牌色。
- 真正决定"不同人看到不同界面"的是 CRM 应用视图：一套视图＝适用范围 + 优先级 + 菜单项 + 工作台首页。
- 工作台首页放的是小工具、提醒、待办、驾驶舱、报表、网站、轮播图、聚合器，顶部筛选器默认全局生效、个别报表可改独立筛选。
- 数量门槛记两个：Web 主导航（网页端左上角）一次最多展示 8 个应用，App 主导航最多设 5 个模块。
- 个人级导航优先级高于租户级导航；App 主导航在后台改完，手机上要重新登录才生效。
- Web 自定义页面的前提是先建一个平台应用并启用；自定义菜单项则是把某对象按筛选条件单独挂成一个菜单入口。
- 详情页字段布局只有三种（左对齐 / 居中 / 上下），点完立即生效，没有保存按钮。

## 核心要点

- **界面定制管理定义**：核心是"千企千面"——导航自定义、菜单自定义、页面自定义、应用自定义、品牌色自定义、企业信息自定义、启动图自定义，七类能力合起来，让管理员自行搭建符合业务场景的系统页面，不用等产品排期。
- **本节课两大板块**：① 了解新 UI（2020 年上线，含横纵布局切换、丰富主题色、自定义品牌色）；② 各项页面配置，包括 CRM 菜单项与首页、Web 主导航、App 主导航、Web / App 自定义页面、自定义菜单项、App 启动图、全局字段布局。
- **新 UI 一键切换横纵布局**：纵向（左侧竖排导航，系统默认）↔ 横向（顶部横排、可展开子菜单）一键切换，目的是适配不同角色、不同行业的使用习惯。
- **主题色分电脑端和移动端**：入口是"企业设置 → 主题色"，电脑端和移动端分别配色、分别看效果；预设了普通灰、扣子粉、时尚红等多种配色，也支持自定义品牌色（改成任意颜色或与品牌一致的颜色）。选完点"立即使用"，前端刷新后导航、按钮、选中态全部跟着变。
- **界面定制管理配置入口**：管理后台 → 界面定制管理，下面挂着 Web 主导航、App 主导航、Web 自定义页面、App 自定义页面、自定义菜单项、App 启动图等几块。
- **菜单配置新旧版本差异**：老版本（较早开通的企业）在"界面定制管理"里直接配 CRM 菜单项和首页；新版本要到 CRM 应用里配（应用列表 → CRM 应用 → 编辑），别在两个地方来回找。
- **CRM 菜单项能配四件事**：① 设置适用范围和优先级（同一套系统给不同人不同界面效果）；② 用中间图标决定展示哪些菜单；③ 创建分组、转移分组；④ 新建和管理个人视图。
- **适用范围与优先级**：视图的适用范围可以指定到不同人员/角色/部门，一个人被多套视图覆盖时按优先级取一套生效——这就是"配一套视图、覆盖一批人"的做法。
- **财务专用视图创建演示**：应用列表 → CRM 应用 → 编辑 → 添加视图 → 命名"财务专用" → 分配适用人员（财务部门）→ 再往下配菜单项和首页。
- **菜单项与分组**：左侧是可用对象清单，右侧是已放出的菜单项，中间图标负责添加/隐藏；业务相近的对象可以"创建分组"收进一组（如"销售相关"放线索、客户、商机），已建好的分组还能转移，不用重建。
- **首页能放什么**：快捷展示小工具、提醒、待办、驾驶舱、报表、网站等组件——一键进 CRM 提醒、待办，或者直接在首页用工具、快捷查看报表；工具栏放快速操作入口（日程、导入工具等），图标样式可换，员工点一下就走，不用绕回后台。
- **首页筛选器（全局 / 独立）**：顶部筛选器默认是"全局筛选"，管着首页所有报表的数据范围；个别报表可以设成独立筛选，不走全局条件，用来做精细化对比。
- **首页图表与工具**：图表直接引系统里已有的统计图（客户来源统计、销售排行榜等），可调显示范围和时间条件（本月 / 上季度 / 本年）；工具类放导入、签入这类常用操作，点开即用。
- **网站、轮播图、列表、聚合器**：网站组件把网页（如企业官网）嵌进首页；轮播图放企业文化图；列表组件展示对象的快捷列表；聚合器是个容器，一个聚合器里能塞多个图表，省首页空间。
- **多视图管理与效果验证**：一个企业可以建财务、销售、管理多套视图，员工只看到分给自己的那套——配好保存后，用财务角色刷新前端进"财务专用"，左侧只剩财务相关菜单、首页就是刚配的图表和工具，跟销售视图完全是两个界面；员工还能新建和管理个人视图，前端顶部可切换自己有权限的视图，管理员可做"视图预览"看别人的界面。
- **Web 主导航（也叫外部主大行）**：网页端左上角那排导航模块，一次最多展示 8 个；设置位置是"管理 → 界面定制管理 → web 主导航"，应用可拖动排序，也可以把藏起来的应用"放出来"展示。
- **个人级导航优先于租户级导航**：企业开启"允许员工自定义"后，员工能自己排顺序、隐藏应用，个人配置优先级高于租户级；配乱了点"恢复默认设置"回到企业级配置。
- **App 主导航的数量与类型**：设的是手机 APP 上的一级菜单，最多可设 5 个模块，模块分三类——应用类、对象类、页面类；支持按部门或用户角色给不同菜单组合，比如单独给售后工程师配一套，跟其他角色不一样。
- **App 主导航的生效方式与鸿蒙适配**：后台改完主导航，移动端要重新登录才生效；纯鸿蒙系统、纷享 App 手机端 955 版本以下，默认适配"适用平台"为"第三方平台"的 app 主导航，如果后台没这个选项，就申请"APP 主导航支持第三方平台"这个灰度项。
- **Web 自定义页面**：给自建应用加自定义内容——先新建一个平台应用、编辑应用并**启用应用**，应用本身自带菜单项，然后再在下面创建 web 自定义页面（选模板或空白、加组件），最后才在视图里放出来。
- **App 自定义页面**：先创建 App 自定义页面，再把 App 主导航指向这个页面，页面就能独立出现在手机上的一级菜单里，不挂在某个对象下面。
- **自定义菜单项**：界面定制管理 → 自定义菜单项 → 新建 → 填菜单项名（投诉工单）→ 选对象（工单）→ 加筛选条件（业务类型 = 投诉）→ 保存 → 在视图菜单项里放出来；前端点这个菜单项，直接就是筛好的投诉工单列表，不用先进工单再筛。
- **App 启动图**：界面定制管理里上传企业自己的图片作为 APP 启动画面（老叫法"系统图/品牌图"），logo 也能作为品牌展示图使用。
- **全局字段布局配置**：在 CRM 模块客户详情页右上角"布局设置"里选，三种排布——左对齐（字段名在左、值在右，默认）、居中、上下（字段名在上、值在下）；选中立即生效、刷新即可看到，没有保存按钮。
- **客服工作台侧边栏**：企业用了纷享"服务通"后，可以在右侧配客服工作台的服务接待页面，一线客服不用跳来跳去就能处理服务工单。

## 结构与流程

### 界面定制管理全景

```
界面定制管理（管理后台入口）
├── Web 主导航（外部主大行）
│ ├── 网页端左上角导航模块，一次最多展示 8 个
│ ├── 纵向 ↔ 横向一键切换（新 UI）
│ ├── 应用可拖动排序，也可"放出来"展示
│ ├── 个人级导航优先级高于租户级导航
│ └── 主题色：企业设置→主题色（电脑端/移动端分开配）+ 自定义品牌色
├── App 主导航（移动端）
│ ├── 手机 APP 一级菜单，最多 5 个模块
│ ├── 模块类型：应用类 / 对象类 / 页面类
│ ├── 按部门或用户角色设不同菜单组合
│ ├── 后台改完，移动端需重新登录才生效
│ └── 鸿蒙：955 版本以下默认走"第三方平台"主导航，没选项就申请灰度项
├── CRM 应用视图（千企千面的核心）
│ ├── 新建视图→命名→设适用范围与优先级
│ ├── 菜单项：中间图标决定展示哪些菜单，可创建/转移分组
│ ├── 个人视图：员工可自行新建和管理
│ ├── 工作台首页：小工具 / 提醒 / 待办 / 驾驶舱 / 报表 / 网站 / 轮播图 / 聚合器 / 筛选器
│ ├── 工具栏：快速操作入口
│ └── 视图预览：管理员可看其他角色的界面
├── Web 自定义页面
│ ├── 前提：先新建平台应用 → 编辑 → 启用应用
│ ├── 应用自带菜单项，再建 web 自定义页面
│ └── 页面加组件（对象/报表/工具/轮播图），在视图里放出来
├── App 自定义页面
│ └── 建好后指到 App 主导航，独立成为手机端一级菜单
├── 自定义菜单项（快捷入口）
│ ├── 新建→命名→选对象→加筛选条件→保存
│ └── 在视图菜单项里放出来，员工点进去直接是筛好的数据
├── App 启动图
│ └── 上传企业图片作为 APP 启动画面（老叫法系统图/品牌图）
└── 全局字段布局配置（CRM 模块内）
 ├── 入口：CRM→客户→详情页右上角"布局设置"
 ├── 三种：左对齐（默认）/ 居中 / 上下
 └── 选中立即生效，无需保存
```

### 应用视图创建步骤（以"财务专用视图"为例）

```
① 应用列表 → CRM 应用 → 编辑
 ↓
② 添加视图 → 命名"财务专用" → 设适用范围与优先级（财务部门）
 ↓
③ 菜单项配置
  - 左侧可用对象 → 中间图标添加到右侧已选
  - 创建分组（如"财务相关"）→ 把收入目标、销售订单等放组里
  - 分组可转移，不用重建
 ↓
④ 工作台首页配置
  - 加筛选器（全局 / 独立）
  - 加图表（销售达成、目标完成率等）
  - 加工具（导入工具、日程）、提醒 / 待办
  - 加轮播图、聚合器（多图表容器）、网站
 ↓
⑤ 工具栏配置 → 添加快速操作入口
 ↓
⑥ 保存 → 点"立即使用"
 ↓
⑦ 前端验证 → 用财务角色账号刷新登录，菜单 + 首页完全匹配财务需求
```

## 术语表

| 术语 | 含义 |
| --- | --- |
| 界面定制管理 | 管理后台模块，用于自定义导航、菜单、页面、主题色等实现千企千面 |
| 千企千面 | 指每家企业可搭出自己的一套界面，而不是所有人共用同一个样子 |
| 新 UI | 2020年上线的界面能力升级，含纵向/横向导航切换、丰富主题色、自定义品牌色 |
| 纵向导航 | 左侧竖排菜单的导航布局，是系统默认布局 |
| 横向导航 | 顶部横排菜单、支持展开子菜单的导航布局 |
| 应用视图 | 界面定制核心概念——按角色/部门创建的独立界面配置（菜单+工作台+工具栏） |
| 适用范围 | 视图/模板分配给哪些角色、部门或人员，决定谁能看到这套界面 |
| 视图优先级 | 一个人被多套视图覆盖时，按优先级取其中一套生效 |
| 个人视图 | 员工自己新建和管理的菜单组合，与管理员配的企业视图并存 |
| 工作台首页 | 每个应用视图的首页，可配置筛选器、图表、工具、轮播图、聚合器等组件 |
| 全局筛选器 | 工作台顶部的筛选条件，默认控制所有报表的数据范围 |
| 独立筛选 | 个别报表不受全局筛选影响，自己设数据范围 |
| 驾驶舱 | 首页上的一类数据看板组件，用来集中看关键指标 |
| 聚合器 | 工作台首页上的"组件容器"，一个聚合器里可以放多个图表 |
| Web 主导航 | 网页端左上角的导航模块，一次最多展示 8 个应用；老教材叫"外部主大行" |
| APP 主大行 | 移动端一级导航菜单，最多 5 个模块，模块分应用类/对象类/页面类 |
| 租户级导航 | 管理员给整个企业配的导航，作为所有员工的默认值 |
| 个人级导航 | 员工在自己账号里调整的导航顺序与显隐，优先级高于租户级 |
| 自定义页面 | 像搭积木一样组合组件的独立页面，可嵌入网页 |
| 平台应用 | 自建的应用容器，Web 自定义页面必须先挂在它下面 |
| 自定义菜单项 | 某对象按某筛选条件单独挂成菜单项（如"投诉工单"） |
| App 启动图 | 手机 APP 打开时的启动画面，可换成企业自己的图 |
| 全局字段布局配置 | 详情页里字段名与字段值的整体排布方式：左对齐/居中/上下 |
| 第三方平台（适用平台） | App 主导航的一个适配选项，纯鸿蒙低版本客户端默认走这一套 |

## 需要注意的点

1. **Web 8 个、App 5 个，别记混**：网页端主导航一次最多展示 **8 个**应用，多的进"更多入口"；手机端 App 主导航最多只能设 **5 个**模块。两者数值不一样，也不互相继承，改一端不影响另一端。
2. **个人级导航压过租户级导航**：员工自己调过顺序后，管理员再改企业级配置，这些员工不会自动跟着变——因为个人级优先级更高。要么通知员工点"恢复默认设置"，要么就接受这个差异。
3. **App 主导航改完必须重新登录**：后台保存后，手机上不会自动刷新，必须退出重新登录才看到新菜单。给客户演示前一定先退登一次，否则会以为没生效。
4. **主题色是"刷新"才看到，不是实时推送**：点"立即使用"后要刷新前端页面；另外电脑端和移动端是分开配的，只改了电脑端，手机上看不出变化。
5. **鸿蒙设备的特殊处理**：纯鸿蒙系统、纷享 App 手机端 955 版本以下，默认只认"适用平台 = 第三方平台"的 app 主导航；如果后台没有这个选项，要申请"APP 主导航支持第三方平台"灰度项，别在别的模板里反复试。
6. **老版本企业在界面定制管理配菜单**：较早开通的企业，CRM 菜单项和首页的入口在"界面定制管理"里；新版本统一在"应用列表 → CRM 应用 → 编辑"里。先判断企业是老版本还是新版本，能少绕一大圈。
7. **Web 自定义页面要先建平台应用并启用**：不做"新建平台应用 → 编辑 → 启用"这一步，后面根本找不到建页面的入口；应用建了但没启用，同样放不出来。
8. **自定义页面不会自己出现**：Web 页面建完要在应用视图里放出来，App 页面建完要把 App 主导航指向它，员工还要在适用范围之内——三个条件缺一个，界面上就是看不到。
9. **详情页布局没有保存按钮**：选中就生效，刷新页面即见变化。如果效果不对，重新选一种即可，不要去找"保存"。
10. **同一个能力有好几个叫法，讲的时候对齐界面**：讲师口播说"外部主大行"，界面里叫"Web 主导航"；说"系统图/品牌图"，课件里叫"App 启动图"；说"页面布局"，课件第 2.8 节叫"全局字段布局配置"。写文档、给客户讲，以界面现状名称为准。
