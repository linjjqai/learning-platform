# 速览（30 秒看完）

- 本课是配置题系列的最后一道：商机四阶段 + 每个阶段多次沟通费用 + 商机与客户两级统计。
- 四个进行中阶段按赢率推进（30%／60%／80%），另设赢单 100%、输单 0%、无效 0% 三个终结态。
- 沟通费用明细是自建的从对象，靠"查找关联→商机"挂到商机上；没有这个查找关联的对象，阶段任务里根本选不到。
- 每个进行中阶段加一条"创建关联对象"任务，数据范围选"仅已关联商机的数据"，处理人为数据负责人。
- 商机上用两个统计字段求和明细的"费用金额"和"沟通总时长"，客户上再求和商机的"累计沟通总费用"，三层不能跨层。
- 阶段推进器共 5 种任务类型，单阶段任务上限 5 个，阶段可逆、可跳过、可重复执行。
- 输单、无效阶段要勾"支持重新激活"，否则一旦点到输单，结果就改不回来了。
- 沟通总时长必须是数字类型，建成文本类型后统计字段求和不了，只能禁用重建。

## 核心要点

- **题目场景**：某公司做北京市海淀区的招商业务，商机分四个阶段——需求出现（30%）、方案沟通（60%）、报价（80%）、商务谈判（推赢单）。跟进过程中每个阶段都可能沟通多次，每次都要记录当时处在哪个阶段、沟通开始与结束时间、总时长、产生的费用（招待费／交通费／公关费／产品费）和费用总金额。
- **需求拆解四条**：① 定义商机四个进行中阶段，另配赢单／输单／无效三个终结态；② 每次沟通生成一条费用明细；③ 商机上汇总所有明细的总费用与总时长；④ 客户上再聚合该客户所有商机的总费用。
- **先按四步把业务想清楚**：第一步确定商机管理的阶段及各阶段的成交概率；第二步确定每个阶段的关键任务有哪些；第三步确定每个阶段要产生哪些结果、是否需要审核；第四步确定每个阶段的参与角色都有谁。这一步没想清楚，后面配得再对也是错的流程。
- **再在系统里落三步**：① 到管理后台→预设对象→商机2.0 加字段、改商机阶段的选项；② 阶段变更如果需要审核，去审批流程管理配置审批流程（发起对象：商机2.0，触发动作：阶段变更）；③ 到阶段推进流程里配置各阶段的任务要求。
- **商机阶段的配置位置与选项**：管理后台→预设对象→商机2.0→"商机阶段"字段（系统预置的单选字段，不用新建）。选项按 需求出现（进行中）、方案沟通（进行中）、报价（进行中）、商务谈判（进行中）、赢单（赢单）、输单（输单）、无效（无效）配齐，用排序号控制推进顺序，保存后前端按这个顺序展示；只有"进行中"才能继续往后推，赢单／输单／无效是终结态，不再要求建沟通明细。
- **创建"沟通费用明细"自定义对象**：管理后台→对象管理→新建自定义对象，命名"沟通费用明细"，配好编号规则（前缀 + 日期 + 流水号，例如 GF + 年月日 + 三位流水），再与商机建立主从关系。
- **明细对象的字段清单**：当前所处阶段（单选）、沟通开始时间（日期时间）、沟通结束时间（日期时间）、沟通总时长（数字，单位小时）、费用类型（单选：招待费／交通费／公关费／产品费）、费用金额（数字，必填）、沟通内容（多行文本）、关联商机（查找关联→商机，必选）。
- **"当前所处阶段"用默认值自动带出**：该字段的默认值设为"商机阶段名称"（取关联商机的字段值），销售新建明细时不用手选阶段，系统直接带出商机当时所处的阶段。
- **明细必须建"查找关联→商机"**：阶段推进器里"创建关联对象"可选的对象，只能是有查找关联商机2.0 的对象。所以沟通费用明细上这个查找关联字段不只是记录用，它决定了阶段任务能不能选中这个对象。
- **阶段推进器的入口**：管理后台→流程管理→阶段推进器管理，选中商机2.0 后，左侧是阶段列表，右侧是该阶段下的任务；每个阶段的任务都可以单独设置，按公司实际业务要求来配。
- **五种任务类型要分清**：编辑对象（进入该阶段时要填商机或商机关联对象的字段）、创建关联对象（新建或选择一个与商机有关的对象，例如商务谈判阶段创建报价单，本题就是创建沟通费用明细）、批量编辑从对象（批量完善商机的从对象数据，例如信息收集阶段批量编辑商机明细）、操作对象（执行对象的自定义按钮）、空任务（不需要线上操作）。
- **本题每个进行中阶段都放"创建关联对象"任务**：任务里选中"沟通费用明细"，把任务按钮名称设成销售看得懂的动作（如"填写沟通费用"），这样销售在前端推进阶段时才看得到这个入口。
- **单条任务要配四样东西**：按钮名称（前端执行阶段任务时看到的按钮文字）、可选数据范围（从全部数据选、只能选已关联商机的、只能选未关联商机的）、谁来处理本业务（这项任务由谁完成，本题为数据负责人）、任务停留时长（允许停留多久，超时后按设置发超时提醒）。
- **可选数据范围有三档，别抄反场景**：本题沟通费用明细要选"仅已关联商机的数据"，新建时自动挂到当前商机，不用手挑；而课件里报价单那种场景反而建议选"未关联商机2.0的数据"，避免同一张报价单被重复关联，两个场景不要混。
- **阶段详情管五件事**：当前阶段允许停留的时长、完成本阶段任务进入下一阶段时是否需要触发审批、是否允许跳过此阶段直接进入下一阶段、进入条件（进入之前必须满足什么）、完成条件（必须完成该阶段下的一项或多项任务才能结束本阶段）。
- **允许跳过阶段是给老客户留的口子**：销售人员反馈部分二次成交客户不会经过需求出现和信息收集阶段，这种就在对应阶段把"是否允许跳过此阶段"设为"是"。
- **赢单／输单／无效阶段要开重新激活**：因判断失误进到输单或无效的商机，需要能在之后改回进行中阶段，就在输单、无效阶段把"进入该阶段后是否支持重新激活"设为"是"。
- **输单和无效要填原因**：进入输单、无效阶段时要求填写"输单或无效原因"字段，所以这个多行文本字段要提前建在商机2.0 上；如果需要主管把关，再配一条"发起对象：商机2.0、触发动作：阶段变更"的审批流程。
- **商机对象上的两个统计字段**：累计沟通总费用（关联对象选沟通费用明细，统计方式求和，统计字段"费用金额"）、累计沟通总时长（关联对象选沟通费用明细，求和"沟通总时长"）。
- **统计能求和的前提是明细字段为数字类型**："沟通总时长"必须是数字字段，一开始建成单行文本或多行文本，统计字段就选不到它、也求不了和；字段类型建后不能直接改，只能把原字段禁用，再新建一个数字类型的同名字段。
- **客户对象上再聚合一层**：客户对象新建统计字段"累计沟通总费用"，关联对象选"商机"，统计方式求和，统计字段选商机上的"累计沟通总费用"。所以要先建好商机上的统计字段，客户这层才选得到。
- **配完要按链路验四件事**：新建商机→逐阶段推进→在阶段里创建沟通费用明细；看明细的"当前所处阶段"是否自动带出、商机上两个累计值是否随明细增加、客户上的累计值是否把该客户多个商机的费用汇总到一起。
- **阶段视图能直接看分布和金额**：前端商机列表可切阶段视图，按阶段看商机分布，同时看商机预测与金额汇总，展示字段可自定义。
- **阶段推进器的两个硬限制**：单阶段任务上限 5 个，任务别堆；阶段可逆、可跳过、可重复执行，所以历史阶段可以回退重走，统计值也会随之变化。
- **难点不在系统配置**：课件明确说，商机的难点不是会不会点配置，而是怎么划分商机阶段、每个阶段规定哪些动作、以及阶段完成标准怎么定。

## 术语表

| 术语 | 含义 |
| --- | --- |
| 主从关系字段 | 查找关联的一种用法，将两个对象建立父子/主从关联，父对象汇总子对象数据 |
| 自定义对象 | 企业根据业务需要自行创建的业务对象，如本例的"沟通费用明细" |
| 统计字段 | 系统自动汇总关联从对象数据的只读字段，支持求和、平均、最大等统计方式 |
| 默认值 | 字段在新建时自动填充的初始值，可设为关联对象的某个字段值 |
| 字段类型修正 | 字段创建后类型无法直接修改，需先禁用再重新创建为正确类型 |
| 编号规则 | 自定义对象的自动编号格式，通常包含前缀+日期+流水号 |
| 商机2.0 | 纷享预置的商机对象，字段与阶段都从"管理后台-预设对象-商机2.0"进入配置 |
| 预设对象 | 系统自带的标准对象（商机2.0、客户、联系人等），字段可改可加，不用新建 |
| 商机阶段 | 商机2.0 上的系统预置单选字段，选项按 进行中 / 赢单 / 输单 / 无效 四种状态设置 |
| 阶段推进器 | 配置商机各阶段任务、条件与跳转规则的管理工具，入口在流程管理下 |
| 阶段推进流程 | 由各阶段任务串起来的推进流程，可逆、可跳过、可重复执行 |
| 任务类型 | 阶段下任务的处理方式，共编辑对象、创建关联对象、批量编辑从对象、操作对象、空任务五种 |
| 编辑对象 | 进入该阶段时要求填写商机或商机关联对象中的字段 |
| 创建关联对象 | 在阶段里新建或选择一个与商机有关的对象，如报价单、沟通费用明细 |
| 批量编辑从对象 | 在阶段里一次性完善商机的从对象数据，如批量编辑商机明细 |
| 操作对象 | 在阶段里执行对象的自定义按钮 |
| 空任务 | 该阶段不需要线上操作的任务 |
| 可选数据范围 | 创建关联对象时可挑选的数据范围：全部数据、仅已关联商机、仅未关联商机 |
| 任务停留时长 | 一项任务允许停留在该阶段的时长，超时可按设置提醒 |
| 阶段详情 | 阶段级的规则设置，含停留时长、进入条件、完成条件、是否跳过、是否触发审批 |
| 进入条件 | 进入该阶段之前必须满足的条件 |
| 完成条件 | 结束当前阶段、进入下一阶段前必须完成的一项或多项任务 |
| 支持重新激活 | 输单、无效阶段的可选项，开启后已终结的商机可改回进行中阶段 |
| 赢单 / 输单 / 无效 | 商机的三个终结态，赢率为 100% / 0% / 0%，赢单与输单一般不可再随意更改 |
| 触发动作 | 审批流程的触发时机，商机场景常用"阶段变更" |
| 阶段视图 | 商机列表按阶段分组展示的视图，可看阶段分布、商机预测与金额汇总 |
| 商机预测 | 按阶段赢率推算的预计成交金额汇总 |

## 需要注意的点

1. **沟通总时长必须是数字类型**：统计字段只能对数字字段求和。如果一开始建成了文本类型，字段类型又不能直接改，只能把原字段禁用、再新建一个数字类型的字段，否则两个统计字段都白配——这是本题最容易踩的坑。
2. **关联字段建在从对象上，而且决定任务能不能选到它**：关联方向是"沟通费用明细上有查找关联→商机"，不是在商机上建。同时阶段推进器里"创建关联对象"可选的对象只能是有查找关联商机2.0 的对象，没有这个字段，阶段任务里根本选不到沟通费用明细。
3. **统计层级不能跨层**：客户→商机→明细三层，客户上的统计对象必须选"商机"、统计字段选商机上的"累计沟通总费用"。必须先建好商机上的统计字段，客户那层才选得到；直接拿客户去统计明细，层级链条就断了。
4. **默认值只带出创建那一刻的阶段**：默认值取"商机阶段名称"，新建明细时自动填上；之后商机推进到下一阶段，已有明细的"当前所处阶段"不会跟着改，阶段分布报表要按这个前提看。
5. **数据范围别顺手选"全部数据"**：本题选"仅已关联商机的数据"，新建明细自动关联当前商机；选全部数据就得手动挑商机，容易挂到别的商机上。反过来，报价单这类要防重复关联的对象，课件建议选"未关联商机2.0的数据"。
6. **单阶段任务上限 5 个**：四个进行中阶段各要放一条创建明细的任务，还要留给填写预计签约金额、报价单之类的动作，任务数要提前排，超了就得合并。
7. **赢单／输单没开重新激活就改不回来**：商机在赢单、输单阶段如果没有设置"支持重新激活"，点选之后无法再更改结果。业务上可能判断失误，就要提前把这两个阶段的重新激活打开。
8. **重新激活配了但前端不显示，先查历史任务**：如果之前删除过该阶段推进器里的任务，再去配置"支持重新激活"，这个设置不会作用于历史数据，老商机上就看不到重新激活按钮。
9. **阶段可逆、可跳过，统计值会跟着变**：回退阶段或跳过某个阶段，被跳过的阶段不会产生沟通费用明细，商机和客户的累计费用、总时长自然偏低，看报表时要能解释这个差异。
10. **完成条件不勾，任务就形同虚设**：只在阶段里加了任务、没在"完成条件"里勾选"必须完成的阶段任务"，销售一条明细都不建也能直接推进到下一阶段，之前配的任务等于没有约束力。
11. **编号规则影响单据识别**：沟通费用明细的编号规则可自定义前缀（如 GF 代表沟通）、日期格式和流水号位数，配好后新建明细自动生成，后续按编号查单据、对账都靠它，别用默认的乱码式编号。
