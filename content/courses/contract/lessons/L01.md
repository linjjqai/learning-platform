## 速览（30 秒看完）

- 合同 Agent 是 AI 在合同管理领域的垂直应用，聚焦风险管理场景
- 覆盖合同生命周期：起草 → 审核 → 签署 → 履行 → 归档
- 自动识别合同风险条款，给出修改建议
- 支持合同版本对比、关键信息自动提取
- 帮助法务、销售、管理层三层提效

## 核心要点

- **合同风险自动识别**：AI 扫描合同条款库，自动标记高风险条款并给出风险等级
- **智能审核**：预设审核要点模板，合同提交后自动走审核流程
- **版本对比**：新旧合同版本关键变化自动高亮，减少人工逐字比对
- **关键信息提取**：合同金额、签约日期、生效期、付款节点等关键信息结构化提取
- **合规检查**：对接公司法务规则库，自动检查合同是否符合内部合规要求

## 结构与流程

```
合同 Agent 能力全景
├─ 能力矩阵
│   ├─ 风险识别：条款风险标记 + 等级评估
│   ├─ 智能审核：审核要点模板 + 自动流转
│   ├─ 版本对比：关键变更高亮 + AI 解读
│   ├─ 信息提取：金额/日期/付款节点结构化
│   └─ 合规检查：对接法务规则库
├─ 角色价值
│   ├─ 法务：风险排查效率提升
│   ├─ 销售：合同起草更快过审
│   └─ 管理层：合同台账实时可查
└─ 演示：完整合同处理流程
```

## 术语表

| 术语 | 含义 |
| --- | --- |
| 合同 Agent | 聚焦合同管理场景的 AI 智能体，覆盖风险识别、审核、比对等能力 |
| 风险条款库 | 法务团队沉淀的高风险合同条款模板，AI 据此识别风险 |
| 合同台账 | 企业全量合同的结构化清单，包含金额、状态、到期日等关键字段 |
| 合规检查 | 合同是否符合公司内部管理规则和外部法规的自动化检查 |

## 需要注意的点

1. 合同 Agent 的风险识别是辅助判断，最终审核权仍在法务——不要让 AI 决策代替人工
2. 风险条款库需要定期更新，否则跟不上新的业务场景和法规变化
3. 敏感客户的合同数据是否允许 AI 处理，需要先过数据安全评估
