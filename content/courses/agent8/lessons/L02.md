## 速览（30 秒看完）

- 下半部分覆盖 Flow、数据丰富、审批洞察 Agent 三个重磅新能力
- Flow 让 Agent 具备多步骤编排执行能力，不只是单次问答
- 数据丰富打通业务数据与 Agent 知识库，让回答有数据支撑
- 审批洞察 Agent 自动分析审批数据，给出审批优化建议
- 三个能力组合起来，让 Agent 从"对话助手"升级为"决策助手"

## 核心要点

- **Flow 用户手册**：Flow 是 Agent 的多步骤编排引擎，支持条件分支、循环、子流程嵌套。新增的 Flow 模板让复杂流程快速搭建
- **数据丰富功能**：打通 CRM 业务数据与 Agent 知识库，让 Agent 回答基于真实业务数据而非通用知识
- **审批洞察 Agent**：自动分析企业审批数据（审批时长、瓶颈节点、超期原因），给出审批流程优化建议
- **三层能力组合**：Flow 负责编排逻辑 + 数据丰富提供事实依据 + 审批洞察给出决策建议
- **真实场景演示**：以"审批超时根因分析"为例，展示三层能力端到端效果

## 术语表

| 术语 | 含义 |
| --- | --- |
| Flow | Agent 多步骤编排引擎，支持条件判断、循环、子流程嵌套执行 |
| 数据丰富 | Agent 知识库与业务数据打通的功能，让 Agent 回答有数据支撑 |
| 审批洞察 Agent | 自动分析企业审批数据、识别瓶颈、给出优化建议的专属 Agent |
| 子流程 | Flow 中可独立调用的流程片段，便于复用和维护 |

## 需要注意的点

1. Flow 编排要有幂等设计——网络抖动时重复执行不能产生脏数据
2. 数据丰富接入敏感业务模块时要先过数据安全评估
3. 审批洞察 Agent 的分析质量取决于历史数据量，上线前确保有足够数据积累
