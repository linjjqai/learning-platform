## 核心要点

- **2608 月发版功能**：本轮更新聚焦 Agent 开发效率、场景覆盖和用户体验三个维度
- **Agent 应用场景建设**：从"平台有什么"转向"客户能用什么"，已有多个场景落地验证
- **能力分层**：底层能力更新 → 中间件 → 业务场景，层层递进
- **可复用组件**：新增 Agent 模板和 Skill 库，降低场景搭建门槛
- **实战导向**：每发版能力都有对应的场景示例，售前可直接演示

## 术语表

| 术语 | 含义 |
| --- | --- |
| ShareAgent | 纷享销客推出的企业级 Agent 开发与运行平台 |
| Skill | Agent 可调用的预置能力模块，类似函数库 |
| Agent 模板 | 预置的 Agent 场景骨架，二次开发即可快速落地 |

## 需要注意的点

1. 发版能力不等于全部可用——部分是灰度上线，售前演示前确认客户租户是否已开通
2. Skill 库更新后要及时排查之前项目是否受影响，避免 Skill 版本不兼容
3. 场景建设进展按客户行业差异较大，演示时选对行业模板效果更好
