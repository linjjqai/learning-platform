## 速览（30 秒看完）

- 知识库是 AI 时代企业智能化应用的核心底座——承载知识沉淀、治理与复用
- 2.0 重大升级：多源接入、一站式沉淀、持续同步、精细治理
- Agentic RAG 技术将业务数据与知识联查到底，不只是"查文档"
- 赋能群聊、会谈、报价、客服、工单等 5 大业务场景
- 让一线当场能用，让经验回流成资产

## 核心要点

- **多源接入**：支持文档库、网盘、Wiki、数据库、外部 API 等多种知识源统一接入
- **一站式沉淀**：所有知识集中管理，自动去重、打标签、建索引
- **持续同步**：知识源更新后自动同步到知识库，保证知识新鲜度
- **精细权限与状态治理**：谁能看什么、什么知识是正式版、什么是草稿，全链路可控
- **Agentic RAG**：不是简单的"检索增强生成"，而是让 Agent 自主决定"查什么知识 + 查什么数据 + 怎么联查"
- **场景赋能**：群聊、会谈、报价、客服、工单——5 大高频业务场景直接开箱即用

## 需要注意的点

1. 多源接入时要统一知识格式，不同源的文档结构差异大会影响检索效果
2. 权限治理是上线前必做项——敏感知识如果权限没配好，Agent 可能会泄露
3. Agentic RAG 效果依赖知识质量而非数量，100 篇精品知识比 1000 篇粗糙知识效果好
4. 5 大场景只是模板，真正落地需要根据客户业务特点做定制化调整
