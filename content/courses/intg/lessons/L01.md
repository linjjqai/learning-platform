## 速览（30 秒看完）

- 连接对象、集成流、报错排查——三类 Skill 把"逐项手工搭建"变成"一键生成"
- Skill 的核心价值：配置速度提升、问题解决效率提升
- 结合广东美味鲜真实配置场景演示 Skill 用法
- 实施顾问与技术顾问都能用，覆盖集成配置全链路
- 集成平台 1.0 让 Skill 驱动的自动化落地到企业集成场景

## 核心要点

- **Skill 驱动**：Skill 是预置的自动化配置能力，把复杂的多步骤配置封装成一键触发
- **连接对象自动生成**：输入源系统和目标系统的基本信息，Skill 自动生成中间的连接对象与字段映射
- **集成流自动创建**：从数据源到目标系统的完整集成流，Skill 根据业务场景模板自动搭建
- **集成报错自动排查**：集成运行中出现异常，Skill 自动定位问题节点并给出修复建议
- **真实场景验证**：以广东美味鲜的实际集成项目为例，演示 Skill 的端到端效果

## 结构与流程

```
Skill 驱动集成配置流程
├─ 场景选择：选择预定义的集成场景模板
├─ 参数输入：填写源/目标系统信息、关键业务字段
├─ Skill 执行
│   ├─ 连接对象自动生成
│   ├─ 集成流自动创建
│   └─ 字段映射自动匹配
├─ 预览调整：人工确认后微调
└─ 上线运行：集成报错自动排查
```

## 术语表

| 术语 | 含义 |
| --- | --- |
| Skill | 集成平台预置的自动化配置能力模块，封装多步骤操作为一键触发 |
| 集成流 | 从数据源到目标系统的完整数据流转配置，包含触发、转换、写入等节点 |
| 连接对象 | 两个系统之间数据交换的中间实体，定义字段映射和数据格式转换 |
| 集成平台 1.0 | 纷享销客自研的系统集成平台，支持多系统间数据打通与自动化流转 |

## 需要注意的点

1. Skill 生成的集成流需要人工确认关键字段映射，避免自动匹配偏差导致数据错位
2. 接入新系统时先验证 Skill 模板是否覆盖该系统类型，不覆盖需要定制 Skill
3. 报错排查 Skill 依赖集成日志的完整记录，日志关闭时 Skill 无法定位问题
